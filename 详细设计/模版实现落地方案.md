# 模版实现落地方案（方案二：poi-tl）

> **依据**：`详细设计/模版实现技术方案候选.md` 中方案二  
> **技术选型**：poi-tl 模板引擎 + Apache POI 5.2.5  
> **PDF 转换**：LibreOffice 命令行

---

## 一、he 与 tian 分工

### 1.1 分工总览

| 负责人 | 职责范围 | 具体任务 |
|--------|----------|----------|
| **he** | 数据层 + 模板管理 | 数据库设计、实体/Mapper、模板 CRUD 接口、模板推荐接口 |
| **tian** | 渲染层 + 导出功能 | poi-tl 渲染服务、Word/PDF 导出接口、模板文件制作 |

### 1.2 he 负责的任务

**数据库与实体**：
- 编写 Flyway 迁移脚本 `V11__add_template_tables.sql`，创建 `resume_templates` 表
- 创建实体类 `ResumeTemplate.java`
- 创建 Mapper 接口 `TemplateMapper.java`

**业务逻辑**：
- 创建 `TemplateService.java`，实现模板 CRUD 业务逻辑
- 实现模板智能推荐算法（根据用户工作年限、行业、目标岗位推荐）

**接口层**：
- 创建 `TemplateController.java`，实现以下接口：
  - `GET /api/v1/templates` — 获取模板列表（支持分类筛选）
  - `GET /api/v1/templates/{id}` — 获取模板详情
  - `POST /api/v1/templates` — 新增模板
  - `PUT /api/v1/templates/{id}` — 更新模板
  - `DELETE /api/v1/templates/{id}` — 删除模板
  - `GET /api/v1/templates/recommend` — 获取推荐模板

### 1.3 tian 负责的任务

**渲染服务**：
- 创建 `TemplateRenderService.java`，使用 poi-tl 编译模板并渲染数据
- 实现 `renderWord()` 方法，将简历数据填充到模板中

**导出接口**：
- 在 `ResumeController.java` 中新增导出接口：
  - `GET /api/v1/resumes/{id}/export/word?templateId=1` — 导出 Word
  - `GET /api/v1/resumes/{id}/export/pdf?templateId=1` — 导出 PDF

**PDF 转换**：
- 实现 LibreOffice 命令行调用，将生成的 Word 转换为 PDF

**模板文件制作**：
- 获取免费简历模板，添加占位符，放入项目目录（详见第二章）

### 1.4 协作要点

- 两人共用 `resume_templates` 表结构（由 he 定义）
- 模板文件路径约定：`src/main/resources/templates/resumes/{category}/template.docx`
- 占位符约定：`{{name}}`、`{{education}}`、`{{workExperience}}` 等（共 9 个占位符）

## 二、模板文件从哪里来

### 2.1 获取途径（任选其一）

| 途径 | 说明 | 获取方式 |
|------|------|----------|
| **网上下载免费模板** | 最简单，推荐使用 | 搜索「免费简历模板下载 docx」 |
| **自己用 Word 制作** | 从零设计，耗时较长 | 打开 Word，手动排版设计 |
| **Canva 在线设计** | 设计精美，导出为 Word | canva.cn 设计后导出为 .docx |

### 2.2 推荐下载网站

- **超级简历**：[https://www.superresume.cn/templates](https://www.superresume.cn/templates)（部分免费模板）
- **站长素材**：[https://sc.chinaz.com/jianli/](https://sc.chinaz.com/jianli/)（免费简历模板下载）
- **懒人模板**：[https://www.lanrenmb.com/jianli/](https://www.lanrenmb.com/jianli/)（免费下载）

### 2.3 制作步骤

**第一步：下载模板**
1. 打开上述网站，选择喜欢的简历模板
2. 下载为 `.docx` 格式，保存到本地

**第二步：添加占位符**
1. 用 Word 打开下载的模板文件
2. 将模板中的示例文字替换为 poi-tl 占位符：

| 模板中的示例文字 | 替换为占位符 |
|------------------|--------------|
| 张三 | `{{name}}` |
| 138xxxx8888 | `{{phone}}` |
| zhangsan@xxx.com | `{{email}}` |
| 教育经历内容 | `{{education}}` |
| 工作经历内容 | `{{workExperience}}` |
| 项目经验内容 | `{{project}}` |
| 技能内容 | `{{skill}}` |
| 个人简介内容 | `{{summary}}` |

3. 将模板标题替换为 `{{title}}`

**第三步：保存到项目目录**
1. 在 `server/src/main/resources/templates/resumes/` 下创建分类目录：
   - `simple/` — 简约风格
   - `professional/` — 专业风格
   - `creative/` — 创意风格
   - `academic/` — 学术风格
2. 将制作好的模板文件命名为 `template.docx`，放入对应目录

**第四步：配置数据库**
1. 在 `resume_templates` 表中插入模板记录：

```sql
INSERT INTO resume_templates (name, category, preview_url, template_path, applicable_scene) VALUES
('简约风格', '简约', '/templates/previews/simple.png', '/templates/resumes/simple/template.docx', '应届生、初级岗位'),
('专业风格', '专业', '/templates/previews/professional.png', '/templates/resumes/professional/template.docx', '中级、高级岗位、金融、咨询'),
('创意风格', '创意', '/templates/previews/creative.png', '/templates/resumes/creative/template.docx', '设计、创意类岗位'),
('学术风格', '学术', '/templates/previews/academic.png', '/templates/resumes/academic/template.docx', '学术研究、教育类岗位');
```

### 2.4 模板文件目录结构

```
server/src/main/resources/
└── templates/
    ├── resumes/                    # 模板文件
    │   ├── simple/
    │   │   └── template.docx       # 简约风格
    │   ├── professional/
    │   │   └── template.docx       # 专业风格
    │   ├── creative/
    │   │   └── template.docx       # 创意风格
    │   └── academic/
    │       └── template.docx       # 学术风格
    └── previews/                   # 预览图片（可选）
        ├── simple.png
        ├── professional.png
        ├── creative.png
        └── academic.png
```

### 2.5 预览图制作方法

如果需要模板预览图：
1. 打开制作好的 `.docx` 模板文件
2. 使用截图工具截取页面内容
3. 保存为 `.png` 格式，放入 `previews/` 目录

  ```bash
  sudo apt-get update
  sudo apt-get install libreoffice
  ```
- **Docker**：在 Dockerfile 中添加安装命令

### 3.3 数据库迁移脚本

`V11__add_template_tables.sql`：

```sql
CREATE TABLE IF NOT EXISTS resume_templates (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT PRIMARY KEY COMMENT '模板ID',
    name VARCHAR(64) NOT NULL COMMENT '模板名称',
    category VARCHAR(32) NOT NULL COMMENT '分类：简约/专业/创意/学术',
    preview_url VARCHAR(512) COMMENT '预览图路径',
    template_path VARCHAR(255) NOT NULL COMMENT '模板文件路径',
    applicable_scene VARCHAR(128) COMMENT '适用场景',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    INDEX idx_category (category)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='简历模板表';
```
