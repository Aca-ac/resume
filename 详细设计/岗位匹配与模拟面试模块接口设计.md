# 岗位匹配与模拟面试模块接口设计

## 1. 模块概述

本模块覆盖前端「简历优化」「AI 岗位匹配」「AI 模拟面试」三类能力，统一调用阿里云 DashScope 兼容模式（`qwen-plus`），并落库匹配记录与面试会话。

| 能力 | 前端入口 | 后端前缀 |
|------|----------|----------|
| 简历优化 | 简历列表「优化」 | `/api/v1/resumes/{id}/optimize` |
| 岗位匹配 | `/match` | `/api/v1/match` |
| 模拟面试 | `/interview` | `/api/v1/interview` |

**技术栈：** Spring Boot 3 · MyBatis-Plus · RestClient · DashScope Compatible Mode · Flyway

**代码路径：**

| 层级 | 路径 |
|------|------|
| 优化 Controller | `ResumeController#optimizeResume` |
| 优化 Service | `ResumeOptimizeService` |
| 匹配 Controller | `MatchController` |
| 匹配 Service | `MatchService` |
| 面试 Controller | `InterviewController` |
| 面试 Service | `InterviewService` |
| 迁移 | `V6__add_match_records.sql`、`V7__add_interview_tables.sql` |

**依赖配置：**

| 配置项 | 环境变量 | 说明 |
|--------|----------|------|
| `app.ai.qwen.api-key` | `DASHSCOPE_API_KEY` / `QWEN_API_KEY` | 必填，否则 AI 接口返回 500 |
| `app.ai.qwen.base-url` | — | 默认 `https://dashscope.aliyuncs.com/compatible-mode/v1` |
| `app.ai.qwen.model` | — | 默认 `qwen-plus` |

## 2. 通用说明

### 2.1 认证方式

所有接口均需 JWT：

```
Authorization: Bearer <accessToken>
```

`UserIdInterceptor` 解析 Token 的 `sub` 得到 `userId`，注入 `@RequestAttribute Long userId`。简历、会话均按归属用户校验，越权返回 404。

### 2.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 200=成功，其他为业务/系统错误 |
| message | String | 提示信息 |
| data | Object | 业务数据 |

### 2.3 分页结构（PageResult）

| 字段 | 类型 | 说明 |
|------|------|------|
| records | Array | 当前页数据 |
| total | long | 总条数 |
| page | long | 当前页（从 1 开始） |
| size | long | 每页大小 |

### 2.4 限流

| 接口 | RateLimiter key | 限制 |
|------|-----------------|------|
| 简历优化 | `optimize` | 60 秒内最多 20 次 |
| JD 匹配 | `match` | 60 秒内最多 20 次 |
| 开始面试 | `interview` | 60 秒内最多 20 次 |
| 提交回答 | `interview-answer` | 60 秒内最多 40 次 |

## 3. 简历优化接口

### 3.1 AI 优化简历

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/resumes/{id}/optimize` |
| 请求方式 | POST |
| Content-Type | `application/json`（Body 可省略） |
| 功能说明 | 按目标职位优化简历 SUMMARY 正文；**不落库覆盖原简历**，仅返回优化结果供前端预览 |

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| id | Long | 是 | 简历 ID |

**请求 Body（OptimizeRequest，可选）：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| targetRole | String | 否 | 目标职位，如「Java 后端工程师」；为空则按通用优化 |

**请求示例：**

```json
{
  "targetRole": "Java后端开发"
}
```

**响应 data（ResumeVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 简历 ID |
| title | String | 标题 |
| sourceType | String | `MANUAL` / `IMPORT` |
| content | String | **优化后的正文**（非库中原文） |
| updatedAt | String | 原简历更新时间 |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 4,
    "title": "我的简历",
    "sourceType": "IMPORT",
    "content": "……优化后的简历正文……",
    "updatedAt": "2026-07-11 14:39:28"
  }
}
```

**业务规则：**

1. 简历必须属于当前用户，否则 404
2. SUMMARY 为空时返回 400「简历内容为空，请先编辑或导入简历」
3. 未配置 API Key 返回 500「未配置 DASHSCOPE_API_KEY，无法进行 AI 优化」
4. 优化结果不写回数据库；用户确认后需再调更新接口保存

**常见错误：**

| code | message |
|------|---------|
| 404 | 简历不存在 |
| 400 | 简历内容为空，请先编辑或导入简历 |
| 500 | 未配置 DASHSCOPE_API_KEY，无法进行 AI 优化 |
| 500 | AI 优化服务异常：\<status\> |

## 4. 岗位匹配接口

### 4.1 简历与 JD 匹配分析

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/match/jd` |
| 请求方式 | POST |
| Content-Type | `application/json` |
| 功能说明 | 对比简历 SUMMARY 与职位描述，生成 0–100 匹配分与中文分析，并写入 `match_records` |

**请求 Body（MatchJdRequest）：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| resumeId | Long | 是 | 简历 ID |
| jdText | String | 是 | 职位描述原文 |

**请求示例：**

```json
{
  "resumeId": 4,
  "jdText": "岗位职责：负责 Spring Boot 后端开发……任职要求：熟悉 MySQL、Redis……"
}
```

**响应 data（MatchRecordVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 匹配记录 ID |
| resumeId | Long | 简历 ID |
| matchScore | Integer | 匹配分 0–100 |
| analysis | String | 匹配优势、差距与改进建议（中文） |
| createdAt | String | 创建时间 `yyyy-MM-dd HH:mm:ss` |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "resumeId": 4,
    "matchScore": 82,
    "analysis": "1. 技术栈匹配度较高……\n2. 建议补充……",
    "createdAt": "2026-07-11 15:00:00"
  }
}
```

**业务规则：**

1. AI 被要求只输出 JSON：`{"matchScore":85,"analysis":"..."}`，服务端解析后入库
2. 解析失败时可能降级为默认分数 + 原文分析（以实现为准）
3. 简历内容取自 `resume_details.section_type = SUMMARY`

**常见错误：**

| code | message |
|------|---------|
| 400 | 请选择简历 |
| 400 | 请粘贴职位描述 |
| 400 | 简历内容为空，请先完善简历 |
| 404 | 简历不存在 |
| 500 | 未配置 DASHSCOPE_API_KEY，无法进行匹配分析 |

---

### 4.2 匹配历史

| 项目 | 内容 |
|------|------|
| 接口路径 | `GET /api/v1/match/history` |
| 请求方式 | GET |
| 功能说明 | 分页查询当前用户的匹配记录，按创建时间倒序 |

**Query 参数：**

| 参数名 | 类型 | 必填 | 默认 | 说明 |
|--------|------|------|------|------|
| page | int | 否 | 1 | 页码，小于 1 时按 1 处理 |
| size | int | 否 | 50 | 每页条数；非法或 >100 时回退为 50 |

**响应 data：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "id": 1,
        "resumeId": 4,
        "matchScore": 82,
        "analysis": "……",
        "createdAt": "2026-07-11 15:00:00"
      }
    ],
    "total": 1,
    "page": 1,
    "size": 50
  }
}
```

## 5. 模拟面试接口

### 5.1 开始面试

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/interview/start` |
| 请求方式 | POST |
| Content-Type | `application/json` |
| 功能说明 | 创建面试会话，基于简历与目标职位生成第一道面试题并写入消息表 |

**请求 Body（InterviewStartRequest）：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| resumeId | Long | 是 | 简历 ID |
| jobTitle | String | 否 | 目标职位；空则使用「通用岗位」 |

**请求示例：**

```json
{
  "resumeId": 4,
  "jobTitle": "Java后端"
}
```

**响应 data（InterviewSessionVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 会话 ID |
| jobTitle | String | 目标职位 |
| status | String | `ONGOING` |
| report | String | 此时为 null |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "jobTitle": "Java后端",
    "status": "ONGOING",
    "report": null
  }
}
```

**业务规则：**

1. 创建会话后立即调用 AI 生成第一题，角色为 `assistant`，`sort_order = 1`
2. 前端应再调「拉取消息」展示首题
3. 简历 SUMMARY 为空则无法开始

**常见错误：**

| code | message |
|------|---------|
| 400 | 请选择简历 |
| 400 | 简历内容为空，请先完善简历 |
| 404 | 简历不存在 |
| 500 | 未配置 DASHSCOPE_API_KEY，无法进行模拟面试 |

---

### 5.2 拉取对话消息

| 项目 | 内容 |
|------|------|
| 接口路径 | `GET /api/v1/interview/{sessionId}/messages` |
| 请求方式 | GET |
| 功能说明 | 按 `sort_order` 升序返回会话全部消息（分页参数保留，当前实现返回全量列表） |

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sessionId | Long | 是 | 会话 ID |

**Query 参数：**

| 参数名 | 类型 | 必填 | 默认 | 说明 |
|--------|------|------|------|------|
| page | int | 否 | 1 | 页码 |
| size | int | 否 | 200 | 每页大小 |

**响应 data.records 元素（InterviewMessageVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| role | String | `user`（候选人）/ `assistant`（面试官） |
| content | String | 消息正文 |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "records": [
      {
        "role": "assistant",
        "content": "请介绍一下你在 Chronos 项目中的职责？"
      }
    ],
    "total": 1,
    "page": 1,
    "size": 200
  }
}
```

### 5.3 提交回答并追问

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/interview/{sessionId}/answer` |
| 请求方式 | POST |
| Content-Type | `application/json` |
| 功能说明 | 保存候选人回答，并基于完整对话历史生成下一道追问 |

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sessionId | Long | 是 | 会话 ID |

**请求 Body（InterviewAnswerRequest）：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| answer | String | 是 | 候选人回答，不能为空 |

**请求示例：**

```json
{
  "answer": "我主要负责任务状态机与权限校验模块……"
}
```

**响应 data（InterviewMessageVO）：**

返回新生成的面试官追问（`role=assistant`）。

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "role": "assistant",
    "content": "状态机里 DONE 之后还能回退吗？为什么这样设计？"
  }
}
```

**业务规则：**

1. 会话状态为 `DONE` 时不可再回答
2. 先写 `user` 消息，再写 `assistant` 追问
3. System Prompt 要求「一次只问一个问题，不要评价」

**常见错误：**

| code | message |
|------|---------|
| 400 | 面试已结束，请查看报告或开启新面试 |
| 400 | 回答不能为空 |
| 404 | 面试会话不存在 |

---

### 5.4 生成面试报告

| 项目 | 内容 |
|------|------|
| 接口路径 | `GET /api/v1/interview/{sessionId}/report` |
| 请求方式 | GET |
| 功能说明 | 根据完整对话生成中文面试报告；首次生成后写入会话并将状态置为 `DONE`；再次请求直接返回已存报告 |

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| sessionId | Long | 是 | 会话 ID |

**响应 data（InterviewSessionVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 会话 ID |
| jobTitle | String | 目标职位 |
| status | String | 生成后为 `DONE` |
| report | String | 报告正文（整体表现、优点、不足、改进建议） |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "jobTitle": "Java后端",
    "status": "DONE",
    "report": "【整体表现】……\n【优点】……\n【不足】……\n【改进建议】……"
  }
}
```

**业务规则：**

1. 报告已存在时幂等返回，不再重复调用 AI
2. 生成成功后 `status = DONE`，后续不可再 `answer`

## 7. 前端对接要点

| 前端模块 | API 文件 | 注意 |
|----------|----------|------|
| 简历优化 | `web/src/api/resume.ts` | 路径必须带 `/v1`；响应需 unwrap `Result.data` |
| 岗位匹配 | `web/src/api/match.ts` | `/v1/match/jd`、`/v1/match/history` |
| 模拟面试 | `web/src/api/interview.ts` | start → messages → answer → report |

**错误示例（已修复）：** 请求 `/api/interview/start`（缺少 `v1`）会被 Spring 当成静态资源，返回 500「No static resource api/interview/start」。
