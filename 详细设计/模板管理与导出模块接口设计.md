# 模板管理与导出模块接口设计

## 1. 模块概述

本模块覆盖「模板数据管理」「模板文件上传」「智能推荐」「模板占位符渲染」「Word/PDF 导出」「临时文件下载与清理」。

| 能力 | 后端前缀 |
|------|----------|
| 模板 CRUD / 上传 / 推荐 | `/api/v1/templates` |
| 模板化导出 | `/api/v1/resumes/export` |
| 导出文件下载 | `/api/v1/files/download` |

**技术栈：** Spring Boot 3 · MyBatis-Plus · poi-tl · PDFBox（CJK）· Flyway · Spring Scheduler

**代码路径：**

| 层级 | 路径 |
|------|------|
| Controller | `com.resume.module.template.controller.*` |
| Service | `com.resume.module.template.service.*` |
| 占位符 | `com.resume.module.template.support.TemplatePlaceholders` |
| 清理任务 | `com.resume.module.template.task.ExportFileCleanTask` |
| 迁移 | `V8__add_templates.sql` |

**存储目录：**

```
uploads/templates/docx/      # Word 模板
uploads/templates/preview/   # 预览图
uploads/exports/             # 临时导出文件（默认 24h 过期）
```

## 2. 通用说明

### 2.1 认证方式

导出与下载接口需要 JWT；模板管理接口当前同样通过拦截器注入 `userId`（推荐接口可不依赖用户归属）：

```
Authorization: Bearer <accessToken>
```

`UserIdInterceptor` 解析 Token 的 `sub` 得到 `userId`，注入 `@RequestAttribute Long userId`。

### 2.2 统一响应格式

```json
{
  "code": 200,
  "message": "success",
  "data": { }
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 200=成功，其他为错误 |
| message | String | 提示信息 |
| data | Object | 业务数据 |

### 2.3 分页结构（PageResult）

| 字段 | 类型 | 说明 |
|------|------|------|
| records | Array | 当前页数据 |
| total | long | 总条数 |
| page | long | 当前页（从 1 开始） |
| size | long | 每页大小 |

### 2.4 文件下载响应

`GET /api/v1/files/download/{fileId}` 返回 **二进制流**，不使用 JSON 包装：

- Word：`Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document`
- PDF：`Content-Type: application/pdf`
- `Content-Disposition: attachment; filename*=UTF-8''...`

### 2.5 相关配置

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `app.storage.template-dir` | `uploads/templates` | 模板根目录 |
| `app.storage.export-dir` | `uploads/exports` | 导出临时目录 |
| `app.storage.export-ttl-hours` | `24` | 导出文件保留小时数 |
| `app.storage.max-file-size` | `104857600` | 上传大小上限（100MB） |

## 4. 占位符规范

Word 模板使用 **poi-tl** 语法，正文中直接写双花括号标签：

| 占位符 | dataMap key | 含义 | 数据来源 |
|--------|-------------|------|----------|
| `{{name}}` | name | 姓名/标题 | 默认取简历 `title`，可从 BASIC/SUMMARY 解析 |
| `{{phone}}` | phone | 电话 | SUMMARY/BASIC 文本启发式提取 |
| `{{email}}` | email | 邮箱 | 同上 |
| `{{school}}` | school | 学校 | 同上 |
| `{{major}}` | major | 专业 | 同上 |
| `{{city}}` | city | 城市 | 同上 |
| `{{education}}` | education | 教育经历 | `resume_details.section_type=EDUCATION` |
| `{{experience}}` | experience | 工作经历 | `WORK_EXPERIENCE` / `WORK` |
| `{{project}}` | project | 项目经历 | `PROJECT` |
| `{{skills}}` | skills | 技能 | `SKILL` / `SKILLS` |
| `{{summary}}` | summary | 自我评价/正文 | `SUMMARY`；为空时拼接其它分段 |

**section_type 映射：**

| section_type | 占位符 |
|--------------|--------|
| EDUCATION / EDU | education |
| WORK_EXPERIENCE / WORK / EXPERIENCE | experience |
| PROJECT / PROJECTS | project |
| SKILL / SKILLS | skills |
| SUMMARY / BASIC / PROFILE / SELF | summary |
| 其它 | 归入 summary |

**维护约定：** 模板内标签 key 勿改名；前端传简历 `resumeId` 即可，后端自动组装 dataMap。

## 5. 模板管理接口

### 5.1 新增模板

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/templates` |
| Content-Type | `multipart/form-data` |
| 功能说明 | 创建模板元数据，并可同时上传 docx / 预览图 |

**表单字段：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| name | String | 是 | 模板名称 |
| category | String | 否 | 默认「通用」 |
| applicableScene | String | 否 | 适用场景 |
| templatePath | String | 否* | 已上传的相对路径（与 file 二选一） |
| previewUrl | String | 否 | 已上传预览图路径 |
| file | File | 否* | `.docx` 模板文件 |
| preview | File | 否 | `.jpg/.jpeg/.png` 预览图 |

\* `file` 与 `templatePath` 至少提供其一。

**响应 data（TemplateVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 模板 ID |
| name | String | 名称 |
| category | String | 分类 |
| previewUrl | String | 预览相对路径 |
| templatePath | String | 模板相对路径 |
| applicableScene | String | 适用场景 |
| createdAt / updatedAt | String | `yyyy-MM-dd HH:mm:ss` |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": 1,
    "name": "技术岗简洁",
    "category": "技术岗",
    "previewUrl": "preview/xxx.png",
    "templatePath": "docx/yyy.docx",
    "applicableScene": "Java后端开发",
    "createdAt": "2026-07-13 09:00:00",
    "updatedAt": "2026-07-13 09:00:00"
  }
}
```

## 6. 模板推荐接口

### 6.1 按用户画像推荐

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/templates/recommend` |
| Content-Type | `application/json` |
| 功能说明 | 规则引擎打分排序；后续可替换为 ML，接口不变 |

**请求 Body：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| education | String | 否 | 学历，如「本科」「应届」 |
| industry | String | 否 | 行业，如「互联网」 |
| workYears | String | 否 | 工作年限，如「3」「应届」 |
| targetPosition | String | 否 | 目标岗位，如「Java开发」 |

**请求示例：**

```json
{
  "education": "本科",
  "industry": "互联网",
  "workYears": "3",
  "targetPosition": "Java开发"
}
```

**响应 data：** `TemplateRecommendVO[]`（按 score 降序）

| 字段 | 类型 | 说明 |
|------|------|------|
| template | TemplateVO | 模板信息 |
| score | int | 推荐分 |
| reason | String | 推荐理由（分号拼接） |

**规则摘要：**

| 条件 | 加分倾向 |
|------|----------|
| 应届 / 工作年限 ≤1 | 应届生、校园、简洁类 |
| 年限 ≥5 | 商务、管理、资深类 |
| 岗位含 Java/开发/技术 | 技术岗类 |
| 岗位含设计/UI | 设计类 |
| 岗位含管理/经理 | 商务管理类 |
| category=通用 | 兜底 +5 |

## 7. 模板化导出接口

### 7.1 导出 Word

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/resumes/export/word` |
| Content-Type | `application/json` |
| 功能说明 | 校验简历归属 → 组装占位符 → poi-tl 渲染 → 落盘 → 返回下载信息 |

**请求 Body：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| templateId | Long | 是 | 模板 ID |
| resumeId | Long | 是 | 简历 ID |

**请求示例：**

```json
{
  "templateId": 1,
  "resumeId": 100
}
```

**响应 data（ExportResultVO）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| fileId | Long | 用于下载 |
| fileType | String | `WORD` |
| originalName | String | 建议下载文件名 |
| downloadUrl | String | `/api/v1/files/download/{fileId}` |
| expireAt | String | 过期时间 |

**响应示例：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "fileId": 12,
    "fileType": "WORD",
    "originalName": "我的简历-技术岗简洁.docx",
    "downloadUrl": "/api/v1/files/download/12",
    "expireAt": "2026-07-14 09:00:00"
  }
}
```

---

### 7.2 导出 PDF

| 项目 | 内容 |
|------|------|
| 接口路径 | `POST /api/v1/resumes/export/pdf` |
| Content-Type | `application/json` |
| 功能说明 | 同一套 dataMap 拼成结构化文本，经 `ResumeExportService`（CJK 字体）生成 PDF |

**请求 Body：** 同 Word（`templateId` + `resumeId`）

**响应 data：** `fileType` 为 `PDF`，其余字段同 ExportResultVO。

**说明：** PDF **不会** 1:1 还原 Word 排版（无 LibreOffice 转换）；版式以 Word 导出为准，PDF 保证中文可读与内容完整。

## 8. 文件下载接口

### 8.1 下载导出文件

| 项目 | 内容 |
|------|------|
| 接口路径 | `GET /api/v1/files/download/{fileId}` |
| 功能说明 | 校验归属与过期时间后返回二进制流 |

**路径参数：**

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| fileId | Long | 是 | `export_files.id` |

**错误码：**

| code / HTTP | 说明 |
|-------------|------|
| 404 | 文件不存在或不属于当前用户 / 磁盘丢失 |
| 410 | 文件已过期，请重新导出 |

## 10. 联调流程建议

1. 准备含 `{{name}}`、`{{summary}}` 等占位符的 `.docx`
2. `POST /api/v1/templates` 上传并创建模板，记下 `id`
3. 确认已有简历及 `resume_details` 分段数据
4. `POST /api/v1/resumes/export/word` 传入 `templateId` + `resumeId`
5. 用返回的 `downloadUrl` 带 Token 下载
6. （可选）`POST /api/v1/templates/recommend` 验证推荐排序

## 11. 已知限制与优化方向

| 项 | 说明 |
|----|------|
| PDF 排版 | 非 Word 所见即所得；后续可接 LibreOffice / documents4j |
| 预览静态访问 | `previewUrl` 存相对路径，需配合静态资源映射或对象存储 |
| 推荐算法 | 当前为关键词规则；可替换为向量/模型，保持 Recommend 接口不变 |
| 个人信息字段 | phone/email 等依赖 SUMMARY 文本启发式；建议前端结构化写入 details |
