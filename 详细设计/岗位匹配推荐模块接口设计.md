# 岗位匹配推荐模块接口设计

## 1. 接口概览

| API路径 | HTTP方法 | Controller文件 | 功能描述 |
|---------|----------|---------------|----------|
| `/api/v1/match/recommend` | POST | FindJobController.java | 基于简历进行岗位匹配推荐 |
| `/api/v1/match/recommendations` | GET | FindJobController.java | 查询推荐历史记录列表 |
| `/api/v1/match/recommendations/{id}` | GET | FindJobController.java | 查询单条推荐记录详情 |

## 2. 限流配置

| 限流键 | 最大请求数 | 时间窗口 | 适用接口 |
|--------|------------|----------|----------|
| job_recommend | 5 | 60秒 | POST /api/v1/match/recommend |

## 3. 接口详细设计

### 3.1 岗位匹配推荐接口

**接口路径**：`POST /api/v1/match/recommend`

**功能描述**：基于用户简历内容，并行执行联网搜索和平台内匹配，返回整合后的岗位推荐结果。

**限流策略**：5次/60秒

**请求头**：

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | Bearer Token |

**请求体**：

```json
{
    "resumeId": 123,
    "enableWebSearch": true
}
```

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| resumeId | Long | 是 | - | 简历ID |
| enableWebSearch | Boolean | 否 | true | 是否开启联网搜索。true时并行执行路径A（联网搜索）和路径B（平台内匹配）；false时只执行路径B（平台内匹配），若无结果则提示用户当前平台内没有合适岗位，建议开启联网搜索 |

**成功响应**（200 OK）：

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "resumeId": 123,
        "recommendations": [
            {
                "jobName": "Java高级工程师",
                "jdContent": "阿里巴巴-杭州-25K-40K\n职位描述：负责Java后端开发，熟悉Spring Boot、微服务架构...",
                "matchScore": 85,
                "matchReason": "技术栈高度匹配，具有丰富的微服务开发经验",
                "source": "NETWORK",
                "sourceUrl": "https://www.zhipin.com/job_detail/xxx",
                "sourceJobId": null
            },
            {
                "jobName": "后端开发工程师",
                "jdContent": "腾讯-深圳-20K-35K\n职位描述：负责公司核心业务后端开发...",
                "matchScore": 78,
                "matchReason": "工作经验和技能要求基本符合",
                "source": "PLATFORM",
                "sourceUrl": null,
                "sourceJobId": 456
            }
        ],
        "improvementSuggestion": null,
        "createdAt": "2026-07-14T10:30:00"
    }
}
```

**无匹配结果响应**（200 OK，enableWebSearch=true时）：

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "resumeId": 123,
        "recommendations": [],
        "improvementSuggestion": {
            "problemDescription": "简历缺乏明确的项目经验描述，技能标签不够详细",
            "suggestions": [
                "增加具体的项目案例和技术难点解决方法",
                "补充专业技能标签，如Spring Boot、MySQL等",
                "优化个人简介，突出核心竞争力"
            ],
            "priority": "high"
        },
        "createdAt": "2026-07-14T10:30:00"
    }
}
```

**无匹配结果响应**（200 OK，enableWebSearch=false时）：

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "resumeId": 123,
        "recommendations": [],
        "improvementSuggestion": {
            "problemDescription": "当前平台内没有找到合适的岗位",
            "suggestions": [

                "可尝试完善简历后再次匹配"
            ],
            "priority": "medium"
        },
        "createdAt": "2026-07-14T10:30:00"
    }
}
```

**响应字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 响应码，200表示成功 |
| message | String | 响应消息 |
| data.resumeId | Long | 简历ID |
| data.recommendations | Array | 推荐岗位列表 |
| data.recommendations[].jobName | String | 岗位名称 |
| data.recommendations[].jdContent | String | 岗位完整描述内容（JD详情，包含公司、薪资、职责要求等） |
| data.recommendations[].matchScore | Integer | 匹配度评分（0-100），采用5维度加权评分 |
| data.recommendations[].matchReason | String | 匹配度判断理由 |
| data.recommendations[].source | String | 来源：NETWORK（联网搜索）/ PLATFORM（平台内） |
| data.recommendations[].sourceUrl | String | 来源链接（NETWORK时有值，PLATFORM时为null） |
| data.recommendations[].sourceJobId | Long | 平台内岗位ID（PLATFORM时有值，NETWORK时为null） |
| data.improvementSuggestion | Object | 简历改进建议（无匹配时有值） |
| data.improvementSuggestion.problemDescription | String | 问题描述 |
| data.improvementSuggestion.suggestions | Array | 改进建议列表 |
| data.improvementSuggestion.priority | String | 优先级：high/medium/low |
| data.createdAt | String | 创建时间（ISO 8601格式） |

**失败响应**（400 Bad Request）：

```json

    "code": 400,
    "message": "参数错误：resumeId不能为空"
}
```

**失败响应**（403 Forbidden）：

### 3.2 查询推荐历史记录列表

**接口路径**：`GET /api/v1/match/recommendations`

**功能描述**：查询当前用户的岗位推荐历史记录列表，支持分页。

**请求头**：

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| Authorization | String | 是 | Bearer Token |

**请求参数**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| page | Integer | 否 | 1 | 页码 |
| size | Integer | 否 | 20 | 每页数量 |

**成功响应**（200 OK）：

```json
{
    "code": 200,
    "message": "success",
    "data": {
        "content": [
            {
                "id": 1001,
                "resumeId": 123,
                "jobName": "Java高级工程师",
                "matchScore": 85,
                "source": 1,
                "createdAt": "2026-07-14T10:30:00"
            }
        ],
        "total": 50,
        "page": 1,
        "size": 20
    }
}
```

**响应字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| code | Integer | 响应码 |
| message | String | 响应消息 |
| data.content | Array | 推荐记录列表 |
| data.content[].id | Long | 记录ID |
| data.content[].resumeId | Long | 简历ID |
| data.content[].jobName | String | 岗位名称 |
| data.content[].matchScore | Integer | 匹配度评分 |
| data.content[].source | Integer | 来源：1-联网搜索，2-平台内 |
| data.content[].createdAt | String | 创建时间（ISO 8601格式） |
| data.total | Long | 总记录数 |
| data.page | Long | 当前页码 |
| data.size | Long | 每页数量 |

## 6. 评分机制

系统采用统一的5维度加权评分机制：

| 维度 | 权重 | 说明 |
|------|------|------|
| summary_score | 10% | 个人总结匹配度 |
| education_score | 15% | 教育背景匹配度 |
| experience_score | 25% | 工作经历匹配度 |
| skill_score | 25% | 专业技能匹配度 |
| project_score | 25% | 项目经历匹配度 |

综合评分公式：`总分 = summary * 0.10 + education * 0.15 + experience * 0.25 + skill * 0.25 + project * 0.25`

**阈值规则**：匹配度低于30分的岗位直接过滤，不返回给用户。

| 404 | 资源不存在（简历不存在、推荐记录不存在） |
| 500 | 服务异常（推荐服务异常、AI服务异常） |
