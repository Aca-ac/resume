# 岗位管理模块数据库设计

## 1. 概述

本数据库设计文档基于项目架构文档 4.1.6、4.2.10，描述岗位管理模块中目标岗位表和岗位评论表的数据库结构设计。

## 2. 数据库环境

| 项目 | 值 |
| :--- | :--- |
| 数据库类型 | MySQL 8.0+ |
| 存储引擎 | InnoDB |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 迁移工具 | Flyway |

## 3. 表结构设计

### 3.1 目标岗位表（target_jobs）

**表说明**：存储用户个人目标岗位数据，支持手动添加、AI联网搜索补全、社区分享与fork功能。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | NOT NULL, AUTO_INCREMENT, PRIMARY KEY | - | 岗位ID，主键自增 |
| user_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 用户ID，关联用户表 |
| job_name | VARCHAR(255) | NOT NULL | - | 岗位名称 |
| jd_content | MEDIUMTEXT | NULL | NULL | 岗位JD内容（包含公司名称、薪资范围、工作地点、职位描述、任职要求等全部信息） |
| source | TINYINT UNSIGNED | NOT NULL | 0 | 来源：0-手动添加，1-AI联网搜索，2-fork他人岗位 |
| original_job_id | BIGINT UNSIGNED | NULL | NULL | fork来源岗位ID（source=2时必填） |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| PRIMARY KEY | 主键 | id | 主键索引 |
| idx_user_id | 普通索引 | user_id | 加速按用户ID查询 |
| idx_job_name | 普通索引 | job_name | 加速按岗位名称搜索 |
| idx_created_at | 普通索引 | created_at | 加速按创建时间排序查询 |

**状态枚举**：

| source值 | 含义 |
| :--- | :--- |
| 0 | 手动添加 |
| 1 | AI联网搜索 |
| 2 | fork他人岗位 |

**外键约束**：

| 约束名称 | 外键字段 | 关联表 | 关联字段 | 删除策略 |
| :--- | :--- | :--- | :--- | :--- |
| fk_target_job_user | user_id | users | id | CASCADE |
| fk_target_job_original | original_job_id | target_jobs | id | SET NULL |

### 3.2 岗位评论表（job_comments）

**表说明**：存储用户在岗位信息下发表的评论，支持查看所有评论、发表文字评论功能。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | NOT NULL, AUTO_INCREMENT, PRIMARY KEY | - | 评论ID，主键自增 |
| job_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 岗位ID，关联目标岗位表 |
| user_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 用户ID，关联用户表 |
| content | TEXT | NOT NULL | - | 评论内容 |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| PRIMARY KEY | 主键 | id | 主键索引 |
| idx_job_id | 普通索引 | job_id | 加速按岗位ID查询评论 |
| idx_user_id | 普通索引 | user_id | 加速按用户ID查询评论 |
| idx_created_at | 普通索引 | created_at | 加速按创建时间排序查询 |

**外键约束**：

| 约束名称 | 外键字段 | 关联表 | 关联字段 | 删除策略 |
| :--- | :--- | :--- | :--- | :--- |
| fk_comment_job | job_id | target_jobs | id | CASCADE |
| fk_comment_user | user_id | users | id | CASCADE |

## 5. 设计原则

### 5.1 主键设计

- 使用 `BIGINT UNSIGNED` 类型自增主键
- 确保主键值唯一且有序，便于索引优化

### 5.2 索引策略

- 主键自动创建聚簇索引
- 高频查询字段（user_id, job_name）创建普通索引
- 外键字段创建普通索引，加速关联查询

### 5.3 字符集与排序规则

- 使用 `utf8mb4` 支持完整的Unicode字符（包括emoji）
- 使用 `utf8mb4_unicode_ci` 排序规则，支持中文排序

### 5.4 时间戳自动维护

- `created_at`：记录创建时自动设置为当前时间
- `updated_at`：记录更新时自动更新为当前时间

### 5.5 数据权限

- 通过 `user_id` 实现用户数据隔离，用户只能管理自己的岗位
- 所有岗位均为公开，可被所有用户查看

## 6. 安全性设计

### 6.1 数据隔离

- 用户只能编辑和删除自己创建的岗位
- 所有岗位均为公开，可被所有用户查看和fork

### 6.2 Fork机制

- fork他人岗位时，`source` 字段标记为2，`original_job_id` 记录原岗位ID
- fork后生成独立副本，原岗位删除不影响fork副本

### 6.3 内容安全

- 评论内容存储为TEXT类型，支持较长文本
- 应用层需实现内容审核机制，过滤敏感内容
