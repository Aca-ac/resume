# 数据库表结构定义

> **版本说明**：本文档与 Flyway 迁移脚本（`server/src/main/resources/db/migration/`）保持一致，反映 V1 + V4 + V5 执行后的最终表结构。  
> **数据库**：MySQL 8.0 · utf8mb4 · InnoDB  
> **迁移脚本**：`V1__init.sql` → `V4__resume_schema_stitch.sql` → `V5__normalize_resume_storage.sql`

---

## 1. 表关系概览

```
users（用户）
  │
  ├── resumes（简历元数据）
  │     ├── resume_details（简历正文分段）
  │     └── resume_files（上传文件 + OCR/解析文本）
  │
  └── analysis_records（AI 分析记录，规划中，见 §6）
```

**存储分工（V5 之后）：**

| 数据 | 存放位置 |
|------|----------|
| 简历标题、来源、版本 | `resumes` |
| 可编辑全文 / 各分段内容 | `resume_details`（`section_type = SUMMARY` 存全文） |
| 原文件、OCR/解析结果 | `resume_files` |

**Redis（非 SQL 表）：** 邮箱验证码、登录限流等临时数据。

## 2. users — 用户表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 用户 ID |
| email | VARCHAR(255) | NOT NULL, UNIQUE | 登录邮箱 |
| password_hash | VARCHAR(255) | NOT NULL, DEFAULT '' | bcrypt 密码哈希 |
| nickname | VARCHAR(100) | NULL | 昵称 |
| name | VARCHAR(50) | NULL | 姓名 |
| phone | VARCHAR(20) | NULL | 手机号 |
| birth_date | DATE | NULL | 出生日期 |
| education | VARCHAR(50) | NULL | 最高学历 |
| work_years | TINYINT UNSIGNED | NULL | 工作年限 |
| city | VARCHAR(50) | NULL | 所在城市 |
| status | TINYINT UNSIGNED | NOT NULL, DEFAULT 1 | 0=禁用，1=正常 |
| last_login_at | DATETIME | NULL | 最后登录时间 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引：** `uk_email(email)` · `idx_status(status)`

---

## 3. resumes — 简历主表

仅存元数据，**不存正文**（V5 已删除 `content` 列）。

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 简历 ID |
| user_id | BIGINT UNSIGNED | NOT NULL, FK → users.id | 所属用户 |
| title | VARCHAR(255) | NOT NULL, DEFAULT '未命名简历' | 简历标题 |
| source_type | VARCHAR(16) | NOT NULL, DEFAULT 'MANUAL' | `MANUAL`=新建 · `IMPORT`=导入 |
| version | INT UNSIGNED | NOT NULL, DEFAULT 1 | 编辑版本号，每次保存 +1 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引：** `idx_user_id(user_id)`  
**外键：** `fk_resumes_user` → `users(id)` ON DELETE CASCADE

---

## 4. resume_details — 简历明细表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 明细 ID |
| resume_id | BIGINT UNSIGNED | NOT NULL, FK → resumes.id | 所属简历 |
| section_type | VARCHAR(32) | NOT NULL | 分段类型（见下表） |
| section_name | VARCHAR(64) | NOT NULL | 分段标题 |
| content | MEDIUMTEXT | NOT NULL | 分段正文；SUMMARY 为可编辑全文 |
| sort_order | INT UNSIGNED | NOT NULL, DEFAULT 0 | 排序序号 |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL, ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**section_type 枚举：**

| 值 | 用途 |
|----|------|
| SUMMARY | 简历全文（导入/OCR 结果、手动编辑内容） |
| EDUCATION | 教育经历 |
| WORK_EXPERIENCE | 工作经历 |
| PROJECT | 项目经验 |
| SKILL | 技能 |

**索引：** `idx_resume_id(resume_id)`  
**外键：** `fk_details_resume` → `resumes(id)` ON DELETE CASCADE

---

## 5. resume_files — 简历文件表

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 文件 ID |
| user_id | BIGINT UNSIGNED | NOT NULL, FK → users.id | 上传用户 |
| resume_id | BIGINT UNSIGNED | NULL, FK → resumes.id | 关联简历（可为空） |
| file_type | VARCHAR(32) | NOT NULL | JPG / JPEG / PNG / PDF / DOC / DOCX |
| file_path | VARCHAR(512) | NOT NULL | 磁盘存储路径（UUID 文件名） |
| file_size | BIGINT UNSIGNED | NOT NULL, DEFAULT 0 | 文件大小（字节） |
| file_md5 | VARCHAR(32) | NULL | MD5 哈希，用于秒传去重 |
| original_name | VARCHAR(255) | NOT NULL | 原始文件名 |
| ocr_text | MEDIUMTEXT | NULL | PDF/DOC 解析或图片 OCR 文本 |
| parse_status | VARCHAR(16) | NOT NULL, DEFAULT 'PENDING' | 解析状态（见下表） |
| created_at | DATETIME | NOT NULL, DEFAULT CURRENT_TIMESTAMP | 上传时间 |

**parse_status 枚举：**

| 值 | 含义 |
|----|------|
| PENDING | 已上传，待解析/OCR |
| DONE | 解析/OCR 成功 |
| FAILED | 解析失败（如 PDF 无文本层） |
| OCR_FALLBACK | OCR 失败，写入占位提示文本 |

**索引：** `idx_user_id(user_id)` · `idx_resume_id(resume_id)` · `idx_user_md5(user_id, file_md5)`  
**外键：** `fk_files_user` → `users(id)` ON DELETE CASCADE · `fk_files_resume` → `resumes(id)` ON DELETE SET NULL

---

## 6. analysis_records — 简历分析记录表（规划中）

> 实体与 Mapper 已在代码中存在；Flyway 迁移尚未纳入 `db/migration/`，DDL 参考 `详细设计/V2__add_analysis_records.sql`。

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT UNSIGNED | 分析记录 ID |
| user_id | BIGINT UNSIGNED | 发起分析的用户 |
| resume_id | BIGINT UNSIGNED | 被分析简历 |
| summary_score ~ project_score | INT UNSIGNED | 五维度评分（0–100） |
| total_score | INT UNSIGNED | 加权总分 |
| weight_summary ~ weight_project | DECIMAL(3,2) | 各维度权重 |
| suggestions | TEXT | AI 优化建议 |
| status | TINYINT | 0=进行中 · 1=完成 · 2=失败 |
| error_message | VARCHAR(500) | 失败原因 |
| request_id | VARCHAR(64) | 链路追踪 ID |
| created_at / updated_at | DATETIME | 时间戳 |

## 7. Flyway 迁移历史

| 版本 | 脚本 | 主要内容 |
|------|------|----------|
| V1 | `V1__init.sql` | 创建 users、resumes、resume_details、resume_files |
| V4 | `V4__resume_schema_stitch.sql` | 幂等添加 source_type、file_md5 |
| V5 | `V5__normalize_resume_storage.sql` | 添加 parse_status；content 改为 MEDIUMTEXT；迁移并删除 resumes.content |

## 8. 与旧版参考 SQL 的差异

`详细设计/resume_评分参考建表.sql`、`详细设计/用户表.sql` 为早期设计参考，与当前生产结构有以下区别：

- `resumes` 已增加 `source_type`，已移除 `content`
- `resume_files` 已增加 `file_md5`、`parse_status`；`ocr_text` 升级为 MEDIUMTEXT
- `resume_details.content` 由 TEXT 升级为 MEDIUMTEXT

**以 Flyway 迁移 + 本文档为准。**
