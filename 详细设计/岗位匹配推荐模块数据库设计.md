# 岗位匹配推荐模块数据设计

## 1. 数据模型设计

### 1.1 简历语义向量表 (resume_semantic_vector)

用于缓存简历的语义向量，支持修改标记位判断是否需要重新生成。

```sql
CREATE TABLE IF NOT EXISTS resume_semantic_vector (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    resume_id BIGINT UNSIGNED NOT NULL COMMENT '简历ID',
    vector MEDIUMTEXT NOT NULL COMMENT '语义向量JSON数组',
    modified_flag TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '修改标记：0-未修改（可用缓存），1-已修改（需重新生成）',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_resume_id (resume_id),
    KEY idx_modified_flag (modified_flag),
    CONSTRAINT fk_resume_vector_resume FOREIGN KEY (resume_id) REFERENCES resumes(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='简历语义向量表';
```

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT UNSIGNED | 主键自增ID |
| resume_id | BIGINT UNSIGNED | 简历ID，关联resumes.id |
| vector | MEDIUMTEXT | 语义向量JSON数组，存储向量化模型生成的浮点数组 |
| modified_flag | TINYINT UNSIGNED | 修改标记：0-未修改，1-已修改 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间（自动更新） |

**业务规则**：
- 简历首次生成向量时，插入记录，modified_flag=0
- 简历内容更新时，将modified_flag置为1
- 查询向量时，优先使用modified_flag=0的缓存数据

### 1.2 岗位语义向量表 (job_semantic_vector)

用于缓存岗位JD的语义向量，支持修改标记位判断是否需要重新生成。

```sql
CREATE TABLE IF NOT EXISTS job_semantic_vector (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    job_id BIGINT UNSIGNED NOT NULL COMMENT '岗位ID',
    vector MEDIUMTEXT NOT NULL COMMENT '语义向量JSON数组',
    modified_flag TINYINT UNSIGNED NOT NULL DEFAULT 0 COMMENT '修改标记：0-未修改（可用缓存），1-已修改（需重新生成）',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    PRIMARY KEY (id),
    UNIQUE KEY uk_job_id (job_id),
    KEY idx_modified_flag (modified_flag),
    CONSTRAINT fk_job_vector_job FOREIGN KEY (job_id) REFERENCES target_jobs(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='岗位语义向量表';
```

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT UNSIGNED | 主键自增ID |
| job_id | BIGINT UNSIGNED | 岗位ID，关联target_jobs.id |
| vector | MEDIUMTEXT | 语义向量JSON数组，存储向量化模型生成的浮点数组 |
| modified_flag | TINYINT UNSIGNED | 修改标记：0-未修改，1-已修改 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间（自动更新） |

**业务规则**：
- 岗位首次生成向量时，插入记录，modified_flag=0
- 岗位内容更新时，将modified_flag置为1
- 查询向量时，优先使用modified_flag=0的缓存数据

### 1.3 推荐会话表 (recommendation_session)

用于记录每次推荐请求的会话信息，支持无匹配结果时的改进建议存储。

```sql
CREATE TABLE IF NOT EXISTS recommendation_session (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    user_id BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    resume_id BIGINT UNSIGNED NOT NULL COMMENT '简历ID',
    has_match_result TINYINT UNSIGNED NOT NULL DEFAULT 1 COMMENT '是否有匹配结果：0-无，1-有',
    problem_description TEXT NULL COMMENT '问题描述（无匹配时）',
    improvement_suggestions TEXT NULL COMMENT '改进建议JSON数组（无匹配时）',
    suggestion_priority VARCHAR(20) NULL COMMENT '建议优先级：high/medium/low',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    KEY idx_user_id (user_id),
    KEY idx_resume_id (resume_id),
    KEY idx_created_at (created_at),
    CONSTRAINT fk_session_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    CONSTRAINT fk_session_resume FOREIGN KEY (resume_id) REFERENCES resumes(id) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='岗位推荐会话表';
```

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT UNSIGNED | 主键自增ID |
| user_id | BIGINT UNSIGNED | 用户ID |
| resume_id | BIGINT UNSIGNED | 简历ID |
| has_match_result | TINYINT UNSIGNED | 是否有匹配结果：0-无，1-有 |
| problem_description | TEXT | 问题描述（无匹配结果时） |
| improvement_suggestions | TEXT | 改进建议JSON数组 |
| suggestion_priority | VARCHAR(20) | 建议优先级：high/medium/low |
| created_at | DATETIME | 创建时间 |

### 1.4 推荐结果记录表 (match_recommendation)

用于记录岗位推荐结果详情，支持历史查询和数据分析。

```sql
CREATE TABLE IF NOT EXISTS match_recommendation (
    id BIGINT UNSIGNED NOT NULL AUTO_INCREMENT COMMENT '主键ID',
    session_id BIGINT UNSIGNED NOT NULL COMMENT '推荐会话ID',
    user_id BIGINT UNSIGNED NOT NULL COMMENT '用户ID',
    resume_id BIGINT UNSIGNED NOT NULL COMMENT '简历ID',
    job_id BIGINT UNSIGNED NULL COMMENT '平台内岗位ID（来源为PLATFORM时）',
    job_name VARCHAR(255) NOT NULL COMMENT '岗位名称',
    jd_content TEXT NULL COMMENT '岗位完整描述内容（JD详情）',
    match_score INT UNSIGNED NOT NULL DEFAULT 0 COMMENT '匹配度评分（0-100）',
    match_reason TEXT NULL COMMENT '匹配度判断理由',
    source TINYINT UNSIGNED NOT NULL COMMENT '来源：1-NETWORK(联网搜索)，2-PLATFORM(平台内)',
    source_url VARCHAR(1000) NULL COMMENT '来源链接（联网搜索结果）',
    source_job_id BIGINT UNSIGNED NULL COMMENT '平台内岗位原始ID',
    created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    PRIMARY KEY (id),
    KEY idx_session_id (session_id),
    KEY idx_user_id (user_id),
    KEY idx_resume_id (resume_id),
    KEY idx_job_id (job_id),
    KEY idx_source (source),
    KEY idx_created_at (created_at),
    CONSTRAINT fk_rec_session FOREIGN KEY (session_id) REFERENCES recommendation_session(id) ON DELETE CASCADE,
    CONSTRAINT fk_rec_user FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE,
    CONSTRAINT fk_rec_resume FOREIGN KEY (resume_id) REFERENCES resumes(id) ON DELETE CASCADE,
    CONSTRAINT fk_rec_job FOREIGN KEY (job_id) REFERENCES target_jobs(id) ON DELETE SET NULL
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='岗位匹配推荐记录表';
```

**字段说明**：

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | BIGINT UNSIGNED | 主键自增ID |
| session_id | BIGINT UNSIGNED | 推荐会话ID |
| user_id | BIGINT UNSIGNED | 用户ID |
| resume_id | BIGINT UNSIGNED | 简历ID |
| job_id | BIGINT UNSIGNED | 平台内岗位ID（来源为PLATFORM时） |
| job_name | VARCHAR(255) | 岗位名称 |
| jd_content | TEXT | 岗位完整描述内容（JD详情，包含公司、薪资、职责要求等） |
| match_score | INT UNSIGNED | 匹配度评分（0-100） |
| match_reason | TEXT | 匹配度判断理由 |
| source | TINYINT UNSIGNED | 来源枚举：1-联网搜索，2-平台内 |
| source_url | VARCHAR(1000) | 来源链接（联网搜索结果） |
| source_job_id | BIGINT UNSIGNED | 平台内岗位原始ID |
| created_at | DATETIME | 创建时间 |
