# 岗位管理模块接口设计

## 1. 模块概述

岗位管理模块负责处理用户个人目标岗位的CRUD操作、AI联网搜索补全岗位JD、岗位社区分享与fork功能、以及岗位评论功能。基于Spring Boot + MyBatis-Plus实现，采用JWT进行认证鉴权。

## 2. 接口列表

| 接口路径 | HTTP方法 | 所属Controller | 功能描述 |
| :--- | :--- | :--- | :--- |
| `/api/v1/jobs` | POST | JobController | 创建目标岗位 |
| `/api/v1/jobs` | GET | JobController | 查询用户目标岗位列表 |
| `/api/v1/jobs/{id}` | GET | JobController | 查询岗位详情 |
| `/api/v1/jobs/{id}` | PUT | JobController | 更新目标岗位 |
| `/api/v1/jobs/{id}` | DELETE | JobController | 删除目标岗位 |
| `/api/v1/jobs/search` | POST | JobController | AI联网搜索补全岗位JD |
| `/api/v1/jobs/community` | GET | JobController | 分页查询所有社区岗位 |
| `/api/v1/jobs/community/search` | GET | JobController | 根据岗位名称分页查询社区岗位 |
| `/api/v1/jobs/community/{id}` | GET | JobController | 根据岗位ID查询单个社区岗位 |
| `/api/v1/jobs/{id}/fork` | POST | JobController | fork他人岗位创建自己的版本 |
| `/api/v1/jobs/{id}/comments` | GET | JobController | 查询岗位评论列表 |
| `/api/v1/jobs/{id}/comments` | POST | JobController | 发表岗位评论 |

## 3. 接口详细设计

### 3.1 POST /api/v1/jobs

**功能描述**: 用户手动创建目标岗位

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 当前登录用户ID（由网关注入） |
| body | JobCreateRequest | 是 | 创建请求体 |

**请求体结构**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| jobName | String | 是 | 岗位名称 |
| jdContent | String | 否 | 岗位JD内容（包含公司名称、薪资范围、工作地点、职位描述、任职要求等全部信息） |

**响应示例**:

```json
{
    "code": 200,
    "message": "创建成功",
    "data": {
        "id": 10001,
        "jobName": "Java后端开发工程师",
        "jdContent": "公司：XX科技\n薪资范围：20k-35k\n工作地点：北京\n\n岗位职责：\n1. 负责公司核心系统开发...\n\n任职要求：\n1. 本科及以上学历，3年以上Java开发经验...",
        "source": 0,
        "createdAt": "2026-07-12 10:30:00",
        "updatedAt": "2026-07-12 10:30:00"
    }
}
```

### 3.4 PUT /api/v1/jobs/{id}

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 当前登录用户ID（由网关注入） |
| id | Long | 是 | 岗位ID（路径参数） |
| body | JobUpdateRequest | 是 | 更新请求体 |

**请求体结构**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| jobName | String | 否 | 岗位名称 |
| jdContent | String | 否 | 岗位JD内容（包含公司名称、薪资范围、工作地点、职位描述、任职要求等全部信息） |

**响应示例**:

```json
{
    "code": 200,
    "message": "更新成功",
    "data": {
        "id": 10001,
        "jobName": "高级Java开发工程师",
        "jdContent": "公司：XX科技\n薪资范围：25k-40k\n工作地点：北京\n\n岗位职责：\n1. 负责公司核心系统架构设计...\n\n任职要求：\n1. 本科及以上学历，5年以上Java开发经验...",
```

- 仅岗位所有者可更新岗位

### 3.6 POST /api/v1/jobs/search

**功能描述**: AI联网搜索补全岗位JD

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 当前登录用户ID（由网关注入） |
| body | JobSearchRequest | 是 | 搜索请求体 |

**限流配置**: @RateLimiter(key = "job_search", maxCount = 5, duration = 60)

**请求体结构**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| jobName | String | 是 | 岗位名称关键词 |
| existingJd | String | 否 | 已有JD内容（可选，用于AI参考并修正） |

**响应示例**:

```json
{
    "code": 200,
    "message": "搜索成功",
    "data": {
        "jobName": "Java后端开发工程师",
        "jdContent": "公司：XX科技\n薪资范围：20k-35k\n工作地点：北京\n\n岗位职责：\n1. 负责公司核心业务系统的后端开发...\n2. 参与系统架构设计与优化...\n\n任职要求：\n1. 本科及以上学历，计算机相关专业\n2. 3年以上Java开发经验，熟悉Spring Boot框架\n3. 熟悉MySQL、Redis等数据库技术\n4. 具备良好的团队协作能力和沟通能力",
        "sources": [
            "https://www.zhipin.com/job_detail/xxx.html",
            "https://www.lagou.com/jobs/xxx.html"
        ]
    }
}
```

**业务规则**:
- 调用大模型联网搜索接口，获取岗位信息
- 返回岗位JD、任职要求及来源链接供用户交叉验证

### 3.9 POST /api/v1/jobs/{id}/fork

**功能描述**: fork他人岗位创建自己的版本

**请求参数**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| userId | Long | 是 | 当前登录用户ID（由网关注入） |
| id | Long | 是 | 源岗位ID（路径参数） |

**响应示例**:

```json
{
    "code": 200,
    "message": "fork成功",
    "data": {
        "id": 10002,
        "jobName": "Java后端开发工程师",
        "jdContent": "公司：XX科技\n薪资范围：20k-35k\n工作地点：北京\n\n岗位职责：\n1. 负责公司核心系统开发...\n\n任职要求：\n1. 本科及以上学历，3年以上Java开发经验...",
        "source": 2,
        "originalJobId": 10001,
        "createdAt": "2026-07-12 12:00:00"
    }
}
```

**业务规则**:
- 所有岗位均为公开，均可fork
- fork后创建独立副本，source标记为2，originalJobId记录原岗位ID
- 原岗位删除不影响fork副本

## 4. 数据传输对象（DTO）

| JobUpdateRequest | 更新岗位请求 |

### 4.2 响应DTO

| DTO名称 | 用途 |
| :--- | :--- |
| JobVO | 岗位详情响应 |
| JobSimpleVO | 岗位简要信息响应 |

| CommentVO | 评论响应 |
| PageResult\<T\> | 分页结果 |

## 5. 错误码定义

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 请求参数错误 |
| 401 | Token无效或已过期 |
| 403 | 权限不足 |
| 404 | 资源不存在 |
| 429 | 请求过于频繁 |
| 500 | 服务器内部错误 |

| 业务错误码 | 说明 |
| :--- | :--- |
| JOB_001 | 岗位名称不能为空 |
| JOB_002 | 岗位不存在 |

| JOB_004 | 无权修改该岗位 |
| JOB_005 | 无权删除该岗位 |

| JOB_007 | 不能fork自己的岗位 |
| JOB_008 | 评论内容不能为空 |
| JOB_009 | 评论内容过长 |
| JOB_010 | AI搜索失败，请稍后重试 |
