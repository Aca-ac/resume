# 简历分析模块数据库设计

## 1. 概述

本模块数据库设计基于项目中已有的数据库迁移脚本 V6、V8 和 V9，用于存储简历与职位描述（JD）的匹配记录及各维度评分数据，支持雷达图分析展示。

## 2. 表结构设计

### 2.1 match_records 表（JD职位匹配记录）

#### 2.1.1 基础字段（V6版本）

| 字段名 | 数据类型 | 约束 | 默认值 | 注释 |
| :--- | :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | NOT NULL, PRIMARY KEY, AUTO_INCREMENT | - | 匹配记录ID |
| user_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 用户ID |
| resume_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 简历ID |
| jd_text | MEDIUMTEXT | NOT NULL | - | 职位描述原文 |
| match_score | INT UNSIGNED | NOT NULL | 0 | 匹配分 0-100 |

| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

#### 2.1.2 扩展字段（V8版本）

| 字段名 | 数据类型 | 约束 | 默认值 | 注释 |
| :--- | :--- | :--- | :--- | :--- |
| summary_score | INT UNSIGNED | NOT NULL | 0 | 个人总结评分 0-100 |
| education_score | INT UNSIGNED | NOT NULL | 0 | 教育背景评分 0-100 |
| experience_score | INT UNSIGNED | NOT NULL | 0 | 工作经历评分 0-100 |
| skill_score | INT UNSIGNED | NOT NULL | 0 | 专业技能评分 0-100 |

| 索引名称 | 类型 | 字段 | 说明 |

- **排序规则**: utf8mb4_unicode_ci

## 3. 匹配等级规则

| 等级 | 英文标识 | 分数范围 | 说明 |
| :--- | :--- | :--- | :--- |
| 优秀 | excellent | ≥ 85 | 高度匹配 |
| 良好 | good | 70-84 | 较好匹配 |
| 一般 | average | 50-69 | 基本匹配 |
| 较差 | poor | < 50 | 匹配度低 |

## 4. 评分计算规则

### 4.1 传统五维度加权评分

| 维度 | 权重 |
| :--- | :--- |
| 个人总结 | 10% |
| 教育背景 | 15% |
| 工作经历 | 25% |
| 专业技能 | 25% |
| 项目经历 | 25% |

**计算公式**: `match_score = summary_score * 0.10 + education_score * 0.15 + experience_score * 0.25 + skill_score * 0.25 + project_score * 0.25`

### 4.2 雷达图加权评分

雷达图评分支持多种预设维度配置（general/technical/management），各维度权重可配置。

**计算公式**: `match_score = Σ(dimension_score * dimension_weight) / Σ(dimension_weight)`
