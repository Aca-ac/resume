## 1. 概述

| 能力 | 路径前缀 | 负责人 |
|------|----------|--------|
| 模板 CRUD + 推荐 | `/api/v1/templates` | he |

**表：** `resume_templates`（Flyway `V11__add_template_tables.sql`）  
**实体/Mapper：** `ResumeTemplate` / `TemplateMapper`（与 tian 共用）  
**业务：** `TemplateService` · `TemplateController`

种子数据（templateId=1~4）与 classpath 模板对齐：

| id | 名称 | category | template_path |
|----|------|----------|---------------|
| 1 | 简约风格 | 简约 | `/templates/resumes/simple/template.docx` |
| 2 | 专业风格 | 专业 | `/templates/resumes/professional/template.docx` |
| 3 | 创意风格 | 创意 | `/templates/resumes/creative/template.docx` |
| 4 | 学术风格 | 学术 | `/templates/resumes/academic/template.docx` |

**当前文件（每类各一套）：**

| 路径 | 说明 |
|------|------|
| `simple/template.docx` + `simple/preview.png` | 简约 |
| `professional/template.docx` + `professional/preview.png` | 专业 |

**poi-tl 占位符（tian 渲染，均为用户内容）：**

| 占位符 | 含义 | 数据来源 |
|--------|------|----------|
| `{{name}}` | 姓名 | 用户信息 |
| `{{phone}}` | 手机 | 用户信息 |
| `{{email}}` | 邮箱 | 用户信息 |
| `{{education}}` | 教育经历 | `resume_details`，section_type=`EDUCATION` |
| `{{workExperience}}` | 工作经历 | `resume_details`，section_type=`WORK_EXPERIENCE` |
| `{{project}}` | 项目经历 | `resume_details`，section_type=`PROJECT` |

**照片接口（he/tian）：**

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/resumes/{id}/photo` | multipart `file`，JPG/PNG，≤2MB |
| GET | `/api/v1/resumes/{id}/photo` | 返回图片二进制 |
| DELETE | `/api/v1/resumes/{id}/photo` | 删除照片 |

列表/详情 `ResumeVO.photoUrl` 有照片时为 `/api/v1/resumes/{id}/photo`。  
导出文件名仍使用简历标题 `resumes.title`。

## 3. 接口

### 3.1 模板列表

`GET /api/v1/templates?category=&page=1&size=20`

| 参数 | 说明 |
|------|------|
| category | 可选，精确匹配：简约/专业/创意/学术 |
| page / size | 分页，默认 1 / 20 |

### 3.2 模板详情

`GET /api/v1/templates/{id}`

### 3.3 新增模板

`POST /api/v1/templates`  
Content-Type: `application/json`

```json
{
  "name": "简约风格",
  "category": "简约",
  "previewUrl": "/templates/resumes/simple/preview.png",
  "templatePath": "/templates/resumes/simple/template.docx",
  "applicableScene": "应届生、初级岗位"
}
```

### 3.4 更新模板

`PUT /api/v1/templates/{id}` — Body 同新增

### 3.5 删除模板

`DELETE /api/v1/templates/{id}`

### 3.6 智能推荐

`GET /api/v1/templates/recommend?education=&industry=&workYears=&targetPosition=`

| 参数 | 说明 |
|------|------|
| education | 学历，如 本科 / 应届 |
| industry | 行业 |
| workYears | 工作年限 |
| targetPosition | 目标岗位 |

**响应 data：**

```json
[
  {
    "template": { "id": 3, "name": "创意风格", "category": "创意", "...": "..." },
    "score": 45,
    "reason": "匹配设计/创意岗位"
  }
]
```

按 `score` 降序。

## 4. 与 tian / 前端联调

1. 启动后 Flyway 执行 V11，确认 `resume_templates` 有 4 条  
2. `GET /api/v1/templates` 应返回 id=1~4  
3. 预览图：`GET /templates/resumes/simple/preview.png`（无需登录）  
4. 模板导出（tian，详见前端联调文档）：  
   - 推荐：`POST /api/v1/resumes/{id}/export?templateId=&format=word|pdf` → `downloadUrl`  
   - 直接：`GET /api/v1/resumes/{id}/export/word|pdf?templateId=`  
5. 无 `templateId` 时旧 `export/pdf`、`export/docx` 保持不变

Swagger Tag：`简历模板管理`
