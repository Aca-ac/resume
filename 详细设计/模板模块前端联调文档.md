## 1. 模块概述

Sprint2 模板模块包含三块前端能力：

| 页面/能力 | 调用的接口 | 负责人 |
|-----------|------------|--------|
| 模板广场（分类、缩略图、推荐标记） | `/api/v1/templates` | he |
| 模板选择与预览 | 预览图 `/templates/resumes/*` | tian（资源）+ yang（展示） |
| 简历导出（Word / PDF） | `/api/v1/resumes/{id}/export*` | tian |

**数据流简述：**

1. 进入模板广场 → 拉模板列表 / 推荐列表 → 卡片展示 `previewUrl` 缩略图  
2. 用户选中某简历 + 某模板 → 选择格式（word / pdf）→ 发起导出  
3. 导出完成后触发浏览器下载

## 2. 环境与代理

### 2.1 本地开发

| 服务 | 地址 |
|------|------|
| 前端（Vite） | `http://127.0.0.1:5173` |
| 后端（Spring Boot） | `http://127.0.0.1:8080` |

前端 axios `baseURL` 为 `/api`（见 `web/src/utils/request.ts`），Vite 已将 `/api` 代理到 `8080`。

**预览图路径 `/templates/**` 目前未走 `/api` 代理**，开发时二选一：

- **推荐：** 在 `vite.config.ts` 增加代理（与 `/api` 同级）：

```ts
proxy: {
  "/api": { target: "http://127.0.0.1:8080", changeOrigin: true },
  "/templates": { target: "http://127.0.0.1:8080", changeOrigin: true }
}
```

- 或在拼接 `previewUrl` 时写死后端根地址：`http://127.0.0.1:8080` + `previewUrl`

### 2.2 认证

| 路径 | 是否需要 Token |
|------|----------------|
| `/api/v1/templates/**` | 是 |
| `/api/v1/resumes/**` | 是 |
| `/templates/**`（预览图） | **否**（已 `permitAll`） |

请求头：

```
Authorization: Bearer <accessToken>
```

### 2.3 统一 JSON 响应

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

`code !== 200` 时 `message` 为错误说明。

## 3. 模板广场接口（he）

### 3.1 模板列表

```
GET /api/v1/templates?category={category}&page=1&size=20
```

| 参数 | 必填 | 说明 |
|------|------|------|
| category | 否 | 精确匹配：`简约` / `专业` / `创意` / `学术` |
| page | 否 | 默认 `1` |
| size | 否 | 默认 `20` |

**响应 `data`（`PageResult`）：**

```json
{
  "records": [
    {
      "id": 1,
      "name": "简约风格",
      "category": "简约",
      "previewUrl": "/templates/resumes/simple/preview.png",
      "templatePath": "/templates/resumes/simple/template.docx",
      "applicableScene": "应届生、初级岗位",
      "createdAt": "2026-07-13 10:00:00",
      "updatedAt": "2026-07-13 10:00:00"
    }
  ],
  "total": 4,
  "page": 1,
  "size": 20
}
```

**前端展示 `previewUrl`：**

```html
<img :src="previewSrc(template.previewUrl)" :alt="template.name" />
```

```ts
function previewSrc(url: string) {
  // 若已配置 /templates 代理，直接返回 url
  return url.startsWith("http") ? url : url;
}
```

### 3.2 模板详情

```
GET /api/v1/templates/{id}
```

响应 `data` 为单条 `TemplateVO`，字段同列表项。

### 3.3 智能推荐

```
GET /api/v1/templates/recommend?education=&industry=&workYears=&targetPosition=
```

| 参数 | 说明 | 示例 |
|------|------|------|
| education | 学历 | `本科`、`应届` |
| industry | 行业 | `互联网`、`金融` |
| workYears | 工作年限 | `0`、`2`、`5` 或 `3年` |
| targetPosition | 目标岗位 | `UI设计师`、`Java开发` |

**响应 `data`：**

```json
[
  {
    "template": { "id": 3, "name": "创意风格", "category": "创意", "previewUrl": "/templates/resumes/creative/preview.png", "...": "..." },
    "score": 45,
    "reason": "匹配设计/创意岗位"
  }
]
```

按 `score` **降序**排列。`score` 最高的模板可加「推荐」角标。

### 3.4 种子数据（联调对照）

| templateId | 名称 | category | previewUrl |
|------------|------|----------|------------|
| 1 | 简约风格 | 简约 | `/templates/resumes/simple/preview.png` |
| 2 | 专业风格 | 专业 | `/templates/resumes/professional/preview.png` |
| 3 | 创意风格 | 创意 | `/templates/resumes/creative/preview.png` |
| 4 | 学术风格 | 学术 | `/templates/resumes/academic/preview.png` |

预览图可直接访问（无需登录）：

```
GET http://127.0.0.1:8080/templates/resumes/simple/preview.png
```

## 4. 简历导出接口（tian）

导出前需已有简历 `resumeId`（来自简历列表 / 详情）。模板导出会把**当前登录用户信息**（姓名、手机、邮箱）和**简历分段内容**填入模板。

### 4.1 推荐方式：创建导出任务 + 下载

适合导出页「点击导出 → 显示 loading → 自动下载」流程。

#### Step 1：创建导出任务

```
POST /api/v1/resumes/{resumeId}/export?templateId={templateId}&format={format}
```

| 参数 | 必填 | 说明 |
|------|------|------|
| templateId | 是 | 模板 ID，1~4 |
| format | 是 | `word` 或 `pdf`（也接受 `docx`，等同 word） |

**响应 `data`（`ExportResultVO`）：**

```json
{
  "exportId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "resumeId": 2,
  "templateId": 1,
  "format": "pdf",
  "filename": "我的简历.pdf",
  "downloadUrl": "/api/v1/resumes/exports/a1b2c3d4-e5f6-7890-abcd-ef1234567890/download",
  "expiresAt": "2026-07-14 14:30:00"
}
```

| 字段 | 说明 |
|------|------|
| exportId | 本次导出唯一 ID |
| downloadUrl | **相对路径**，需带 Token 请求 |
| expiresAt | 临时文件过期时间（默认 24 小时） |
| filename | 建议用作浏览器保存文件名 |

#### Step 2：下载文件

```
GET /api/v1/resumes/exports/{exportId}/download
```

- 响应为**二进制流**（非 JSON）
- `Content-Type`：`application/pdf` 或 Word docx MIME
- `Content-Disposition`：`attachment; filename*=UTF-8''...`

**注意：** PDF 导出依赖服务端 LibreOffice，首次可能较慢（建议 `timeout: 120000`）。

### 4.2 备选方式：直接下载（一步到位）

无需 `exportId`，适合简单场景；无法拿到 `expiresAt` 等元数据。

| 格式 | 接口 |
|------|------|
| Word | `GET /api/v1/resumes/{resumeId}/export/word?templateId={templateId}` |
| PDF | `GET /api/v1/resumes/{resumeId}/export/pdf?templateId={templateId}` |

响应均为二进制流，处理方式同 4.1 Step 2。

**兼容旧逻辑：** `GET .../export/pdf` **不传** `templateId` 时，走旧版纯文本 PDF 导出（非模板），与模板无关。

### 4.3 与旧导出接口的区别

| 接口 | 是否模板 | 说明 |
|------|----------|------|
| `GET .../export/word?templateId=` | 是 | Sprint2 新增 |
| `GET .../export/pdf?templateId=` | 是 | Sprint2 新增 |
| `POST .../export` | 是 | Sprint2 新增，带临时存储 |
| `GET .../export/docx` | 否 | Sprint1 旧接口，POI 直出 |
| `GET .../export/pdf`（无 templateId） | 否 | Sprint1 旧接口 |
| `GET .../export/text` | 否 | 纯文本 |

模板广场导出应使用 **带 `templateId`** 的接口。

### 4.4 Word 模板占位符（poi-tl）

模板分 4 类（简约/专业/创意/学术），**创建模板时在 `resume_templates.name` 命名即可**，Word 内无需 `{{title}}`。

| 占位符 | 含义 | 数据来源 |
|--------|------|----------|
| `{{name}}` | 姓名 | 用户信息 |
| `{{phone}}` | 手机 | 用户信息 |
| `{{email}}` | 邮箱 | 用户信息 |
| `{{education}}` | 教育经历 | `resume_details`，`section_type=EDUCATION` |
| `{{workExperience}}` | 工作经历 | `resume_details`，`section_type=WORK_EXPERIENCE` |
| `{{project}}` | 项目经历 | `resume_details`，`section_type=PROJECT` |
| `{{skill}}` | 技能证书 | `resume_details`，`section_type=SKILL` |
| `{{summary}}` | 个人总结 | `resume_details`，`section_type=SUMMARY` |

导出文件名仍用简历标题 `resumes.title`，与占位符无关。

## 5. 前端 TypeScript 类型建议

```ts
// web/src/types/template.ts

export interface TemplateVO {
  id: number;
  name: string;
  category: string;
  previewUrl: string;
  templatePath: string;
  applicableScene: string;
  createdAt: string;
  updatedAt: string;
}

export interface TemplateRecommendVO {
  template: TemplateVO;
  score: number;
  reason: string;
}

export interface PageResult<T> {
  records: T[];
  total: number;
  page: number;
  size: number;
}

export interface ExportResultVO {
  exportId: string;
  resumeId: number;
  templateId: number;
  format: "word" | "pdf";
  filename: string;
  downloadUrl: string;
  expiresAt: string;
}

export type ExportFormat = "word" | "pdf";
```

## 6. API 封装示例

可参考现有 `web/src/api/resume.ts` 中 `downloadExport` 的 blob 下载写法。

```ts
// web/src/api/template.ts（建议新建）

import request from "@/utils/request";
import { assertDownloadBlob, downloadBlob } from "@/utils/download";
import type { ExportResultVO, PageResult, TemplateRecommendVO, TemplateVO } from "@/types/template";

interface ApiResult<T> {
  code: number;
  message: string;
  data: T;
}

function unwrap<T>(res: ApiResult<T>): T {
  if (res.code !== 200) throw new Error(res.message || "请求失败");
  return res.data;
}

export function fetchTemplates(category?: string, page = 1, size = 20) {
  const q = new URLSearchParams({ page: String(page), size: String(size) });
  if (category) q.set("category", category);
  return request
    .get<ApiResult<PageResult<TemplateVO>>>(`/v1/templates?${q}`)
    .then(unwrap);
}

export function fetchTemplateDetail(id: number) {
  return request.get<ApiResult<TemplateVO>>(`/v1/templates/${id}`).then(unwrap);
}

export function fetchTemplateRecommend(params: {
  education?: string;
  industry?: string;
  workYears?: string;
  targetPosition?: string;
}) {
  const q = new URLSearchParams();
  Object.entries(params).forEach(([k, v]) => v && q.set(k, v));
  return request
    .get<ApiResult<TemplateRecommendVO[]>>(`/v1/templates/recommend?${q}`)
    .then(unwrap);
}

/** 推荐：POST 创建任务再下载 */
export async function exportResumeByTemplate(
  resumeId: number,
  templateId: number,
  format: "word" | "pdf"
) {
  const job = await request
    .post<ApiResult<ExportResultVO>>(
      `/v1/resumes/${resumeId}/export?templateId=${templateId}&format=${format}`,
      null,
      { timeout: 120000 }
    )
    .then(unwrap);

  const blob = await request.get(job.downloadUrl, {
    responseType: "blob",
    timeout: 60000
  }) as Blob;
  downloadBlob(await assertDownloadBlob(blob), job.filename);
  return job;
}

/** 备选：GET 直接下载 Word */
export async function exportResumeWordDirect(resumeId: number, templateId: number) {
  const blob = await request.get(`/v1/resumes/${resumeId}/export/word?templateId=${templateId}`, {
    responseType: "blob",
    timeout: 120000
  }) as Blob;
  downloadBlob(await assertDownloadBlob(blob), `resume-${resumeId}.docx`);
}
```

## 7. 页面联调流程

### 7.1 模板广场

```
用户进入广场
  → GET /api/v1/templates（可按 category Tab 筛选）
  → 可选：GET /api/v1/templates/recommend（用用户画像参数）
  → 渲染卡片：<img :src="item.previewUrl" />
  → 点击卡片 → 携带 templateId 进入「选择/预览/导出」页
```

### 7.2 导出页

```
用户选择简历 + 模板 + 格式
  → POST /api/v1/resumes/{id}/export?templateId=&format=
  → 展示 loading（PDF 可能 10~60s）
  → 收到 ExportResultVO
  → GET downloadUrl（blob）→ 触发下载
  → 可选：展示 expiresAt「链接 24 小时内有效」
```

### 7.3 一键换肤（AC1.6）

切换模板 = 更换 `templateId`，重新调用导出或仅更新选中状态；**无需**重新拉简历内容（后端按 resumeId 实时读取分段）。

## 8. 错误码与处理

| 场景 | HTTP / code | message 示例 | 前端建议 |
|------|-------------|--------------|----------|
| 未登录 | 401 | — | 跳转登录 |
| 简历不存在 / 无权 | 404 | 简历不存在 | 提示并返回列表 |
| 模板不存在 | 404 | 模板不存在 | 刷新模板列表 |
| 格式错误 | 400 | 请指定导出格式 word 或 pdf | 表单校验 |
| 导出文件过期 | 404 | 导出文件不存在或已过期 | 提示重新导出 |
| PDF 转换失败 | 500 | LibreOffice 相关 | 提示稍后重试或改导 Word |
| 导出超时 | — | axios timeout | 延长 timeout 或提示重试 |

二进制下载接口失败时，响应体可能是 JSON 包在 blob 里，需参考 `resume.ts` 的 `readBlobError` 解析。
