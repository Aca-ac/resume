# 用户认证模块数据库设计

## 1. 概述

本数据库设计文档基于项目初始化SQL脚本，描述用户认证模块中用户表的数据库结构设计。

## 2. 数据库环境

| 项目 | 值 |
| :--- | :--- |
| 数据库类型 | MySQL 8.0+ |
| 存储引擎 | InnoDB |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 迁移工具 | Flyway |

## 3. 表结构设计

### 3.1 用户表（users）

**表说明**：存储系统用户的基本信息，作为认证模块的核心表。

| 字段名 | 类型 | 约束 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | NOT NULL, AUTO_INCREMENT, PRIMARY KEY | - | 用户ID，主键自增 |
| email | VARCHAR(255) | NOT NULL, UNIQUE | - | 邮箱（登录账号，唯一） |
| password_hash | VARCHAR(255) | NOT NULL | '' | 密码哈希（bcrypt加密） |
| nickname | VARCHAR(100) | NULL | NULL | 昵称 |
| name | VARCHAR(50) | NULL | NULL | 姓名 |
| phone | VARCHAR(20) | NULL | NULL | 手机号 |
| birth_date | DATE | NULL | NULL | 出生日期 |
| education | VARCHAR(50) | NULL | NULL | 最高学历（如：本科、硕士、博士） |
| work_years | TINYINT UNSIGNED | NULL | NULL | 工作年限 |
| city | VARCHAR(50) | NULL | NULL | 所在城市 |
| status | TINYINT UNSIGNED | NOT NULL | 1 | 账号状态：0-禁用，1-正常 |
| last_login_at | DATETIME | NULL | NULL | 最后登录时间 |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

**索引设计**：

| 索引名 | 类型 | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| PRIMARY KEY | 主键 | id | 主键索引 |
| uk_email | 唯一索引 | email | 邮箱唯一性约束 |
| idx_status | 普通索引 | status | 账号状态查询优化 |

**状态枚举**：

| status值 | 含义 |
| :--- | :--- |
| 0 | 禁用 |
| 1 | 正常 |

## 4. 数据字典

### 4.1 核心业务实体

| 实体名称 | 对应表 | 说明 |
| :--- | :--- | :--- |
| 用户 | users | 系统登录用户，存储基本身份信息 |

### 4.2 字段分类说明

| 分类 | 字段示例 | 说明 |
| :--- | :--- | :--- |
| 主键字段 | id | 自增主键，唯一标识用户 |
| 认证字段 | email, password_hash | 用户登录认证核心数据 |
| 基本信息字段 | nickname, name, phone, birth_date | 用户个人基本信息 |
| 职业信息字段 | education, work_years, city | 用户职业相关信息 |
| 状态字段 | status | 账号状态标识，用于业务状态流转 |
| 时间字段 | last_login_at, created_at, updated_at | 记录时间戳，支持审计追溯 |

## 5. 设计原则

### 5.1 主键设计

- 使用 `BIGINT UNSIGNED` 类型自增主键
- 确保主键值唯一且有序，便于索引优化

### 5.2 索引策略

- 主键自动创建聚簇索引
- 唯一性约束字段（email）创建唯一索引
- 状态字段（status）创建普通索引，优化筛选查询

### 5.3 字符集与排序规则

- 使用 `utf8mb4` 支持完整的Unicode字符（包括emoji）
- 使用 `utf8mb4_unicode_ci` 排序规则，支持中文排序

### 5.4 时间戳自动维护

- `created_at`：记录创建时自动设置为当前时间
- `updated_at`：记录更新时自动更新为当前时间

## 6. 安全性设计

### 6.1 密码存储

- 密码使用bcrypt算法加密存储，不存储明文密码
- `password_hash` 字段默认为空字符串，兼容社交登录场景

### 6.2 敏感字段

- `phone`：手机号作为可选字段，允许为空
- 建议通过应用层对敏感信息进行脱敏处理

### 6.3 数据权限

- 通过 `id` 主键实现用户数据隔离
- 应用层需实现严格的权限校验逻辑，确保用户只能访问自己的数据

## 7. 扩展考虑

### 7.1 用户扩展字段

- `nickname`、`name`、`phone`、`birth_date`、`education`、`work_years`、`city` 均设计为可空字段
- 支持用户分阶段完善个人信息

### 7.2 登录审计

- `last_login_at` 字段记录用户最后登录时间
- 可扩展实现登录日志表，记录完整的登录历史
