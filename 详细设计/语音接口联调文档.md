# 语音接口联调文档（Sprint3 · tian）

## 接口一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/v1/voice/asr` | 上传音频 → 识别文本 |
| POST | `/api/v1/voice/tts` | 提交文本 → 返回 MP3 二进制 |

均需登录：`Authorization: Bearer <token>`

## 1. 语音识别 ASR

```
POST /api/v1/voice/asr
Content-Type: multipart/form-data
```

| 字段 | 类型 | 说明 |
|------|------|------|
| file | File | wav/mp3/pcm 等，建议 16kHz wav，最大 10MB |

**响应 JSON：**

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "text": "识别出的文字",
    "fileId": "uuid.wav",
    "originalFilename": "recording.wav"
  }
}
```

**实现：** DashScope `paraformer-realtime-v2` + 本地文件识别；失败自动重试 2 次。

## 2. 语音合成 TTS

```
POST /api/v1/voice/tts
Content-Type: application/json
```

```json
{ "text": "您好，请介绍一下你的项目经历。" }
```

**响应：** `Content-Type: audio/mpeg` 二进制流（MP3）。

**实现：** DashScope `cosyvoice-v3-flash`，音色 `longanyang`。

## 3. 配置

`application.yml` → `app.voice.*`；API Key 复用 `DASHSCOPE_API_KEY`。

## 4. 前端封装

`web/src/api/voice.ts`：`recognizeSpeech()`、`synthesizeSpeech()`。

## 5. 面试提示词（he / wang 使用）

| 文件 | 用途 |
|------|------|
| `prompts/interview_question_prompt.txt` | 首题生成 |
| `prompts/interview_answer_eval_prompt.txt` | 回答评估 + 追问（JSON 输出） |
| `prompts/interview_summary_prompt.txt` | 复盘报告 |

加载类：`InterviewPromptService`（占位符 `{{jobTitle}}` 等）。

当前 `InterviewService` 已接入**首题**与**复盘**提示词；回答评估提示词供 he 状态机改造时使用。
