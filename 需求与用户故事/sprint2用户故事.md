## 1 用户故事1：简历模板与模板化导出

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-1 |
| 功能模块 | 简历模板与模板化导出 |
| 涉及角色 | 求职者 |
| 实现方案 | **方案待定**（模板数量、技术选型、视觉风格待团队评审后确定） |

### 标准用户故事句式

1. **作为**求职者，**我希望**从系统提供的简历模板中选择一份适合我的样式，**以便**快速获得专业排版的简历基础框架。
2. **作为**求职者，**我希望**选择模板后系统自动将我的个人信息和简历内容填充到模板对应位置，**以便**无需重复手动录入即可生成完整简历。
3. **作为**求职者，**我希望**按所选模板导出Word或PDF格式简历，**以便**获得可直接投递的正式版本。

### 用户价值

1. 降低简历排版门槛，新手用户也能快速产出格式规范的简历；
2. 复用Sprint1个人中心与简历编辑数据，实现一键填充，提升简历制作效率；
3. 模板化导出保障排版一致性，满足正式投递场景需求。

### 验收标准（AC）

#### AC1 模板选择与预览

| 字段 | 内容 |
|------|------|
| **Given** | 求职者进入简历模板页面，系统已配置至少1套可用模板（具体数量方案待定） |
| **When** | 求职者浏览并点击某份模板 |
| **Then** | 系统展示该模板的预览效果，支持确认选用或返回重新选择 |

#### AC2 模板自动填充

| 字段 | 内容 |
|------|------|
| **Given** | 求职者已在个人中心填写基本信息（参见Sprint1 AC1.5），并已维护简历内容 |
| **When** | 求职者确认使用所选模板 |
| **Then** | 系统自动将姓名、联系方式、教育背景、工作经历等信息填充至模板对应字段，填充准确率100% |

#### AC3 模板化导出

| 字段 | 内容 |
|------|------|
| **Given** | 求职者已完成模板选用与内容填充 |
| **When** | 求职者点击【导出】并选择 .docx 或 .pdf 格式 |
| **Then** | 系统按当前模板样式生成导出文件，排版整洁、无乱码，符合正式投递标准（参见Sprint1 AC2.6） |

## 2 用户故事2：个人目标岗位管理

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-2 |
| 功能模块 | 个人目标岗位库 |
| 涉及角色 | 求职者 |

### 标准用户故事句式

1. **作为**求职者，**我希望**手动添加、编辑、删除自己的目标岗位信息，**以便**维护一份专属的目标职位库，聚焦个人求职方向。
2. **作为**求职者，**我希望**粘贴岗位JD文本后由AI自动解析并填充岗位字段，**以便**快速录入完整岗位信息，减少手动整理成本。
3. **作为**求职者，**我希望**输入岗位关键词后由AI生成岗位描述，**以便**在仅有模糊求职意向时也能快速创建可用的目标岗位条目。

### 用户价值

1. 摒弃全局岗位池与管理员角色，岗位数据完全由用户自主掌控，更贴合个人求职场景；
2. AI辅助录入降低JD整理门槛，支持从完整JD或关键词两种入口快速建岗；
3. 为后续简历-岗位匹配推荐提供用户专属的数据基础。

### 验收标准（AC）

#### AC1 目标岗位手动CRUD

| 字段 | 内容 |
|------|------|
| **Given** | 求职者进入个人目标岗位管理页面 |
| **When** | 求职者执行新增、编辑或删除操作 |
| **Then** | 系统对当前用户的目标岗位列表进行增删改，每条岗位至少包含：岗位名称、公司名称、岗位职责、任职要求、薪资范围（可选）、工作地点（可选）；操作仅影响当前用户自己的岗位库 |

#### AC2 粘贴JD文本AI解析

| 字段 | 内容 |
|------|------|
| **Given** | 求职者在新增/编辑岗位页面，已粘贴一段完整的岗位JD文本 |
| **When** | 点击【AI解析】按钮 |
| **Then** | 系统自动识别并填充岗位职责、任职要求、薪资范围、工作地点等字段；填充后支持用户对所有字段进行手动修正 |

#### AC3 关键词AI生成岗位描述

| 字段 | 内容 |
|------|------|
| **Given** | 求职者在新增岗位页面，输入关键词（如「前端开发工程师 + 腾讯」） |
| **When** | 点击【AI生成】按钮 |
| **Then** | 系统基于关键词自动生成岗位职责与任职要求等描述内容；生成后支持用户对所有字段进行手动修正 |

## 3 用户故事3：简历-岗位匹配推荐

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-3 |
| 功能模块 | AI智能岗位匹配推荐 |
| 涉及角色 | 求职者 |

### 标准用户故事句式

**作为**求职者，**我希望**系统自动解析我的简历，与我已保存的目标岗位做多维度匹配，按综合匹配度排序展示推荐结果，并展示AI生成的推荐理由，**以便**快速筛选高适配职位，聚焦个人求职方向。

### 用户价值

消除求职者信息差，无需手动逐条对比岗位，系统自动完成简历与用户自有岗位的匹配，快速定位高匹配目标，提升求职效率。

### 验收标准（AC）

#### AC1 简历-岗位匹配度计算

| 字段 | 内容 |
|------|------|
| **Given** | 求职者已上传并启用一份有效简历，且个人目标岗位库中至少存在1条岗位 |
| **When** | 进入岗位匹配推荐页面 |
| **Then** | 系统读取简历信息，与当前用户已保存的全部目标岗位进行多维度打分，生成各岗位匹配度数值 |

#### AC2 多维度复合排序

| 字段 | 内容 |
|------|------|
| **Given** | 系统已计算用户全部目标岗位的匹配分数 |
| **When** | 求职者切换排序条件 |
| **Then** | 推荐列表支持按「综合匹配度、薪资、距离」三种维度复合排序展示 |

#### AC3 AI推荐理由展示

| 字段 | 内容 |
|------|------|
| **Given** | 推荐列表加载完成 |
| **When** | 求职者浏览岗位卡片 |
| **Then** | 每张岗位卡片固定展示AI生成的文字化推荐理由，示例：<br>1. 你的React商业项目经验与该岗位高度契合 95%<br>2. 该岗位急需懂跨平台开发的工程师，符合你的技术栈 |

## 4 用户故事4：AI语音模拟面试

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-4 |
| 功能模块 | AI语音模拟面试 |
| 涉及角色 | 缺乏实战面试经验的求职者 |
| 技术方案 | 完整语音面试，语音转文字（STT）与文字转语音（TTS）通过第三方API实现（阿里云/讯飞/腾讯云，具体选型待定） |

### 标准用户故事句式

**作为**缺乏实战面试经验的求职者，**我希望**与AI进行实时语音对话面试，可切换正常/压力两种面试模式；面试结束后自动生成完整面试复盘报告与优化建议，**以便**线下真实面试前完成演练，提升面试能力、缓解面试紧张。

### 用户价值

低成本、无压力完成面试实战训练，提前熟悉面试提问逻辑，修正表达短板，同时掌握标准答题思路，应对真实面试。

### 验收标准（AC）

#### AC1 完整语音交互能力

| 字段 | 内容 |
|------|------|
| **Given** | 求职者进入模拟面试页面 |
| **When** | 点击【开始面试】 |
| **Then** | 1. AI通过语音（TTS）播报面试问题；<br>2. 支持用户直接语音回答；<br>3. 系统通过第三方STT API将用户语音转为文字供AI理解；<br>4. 全程为语音对话模式（非纯文字交互），交互延迟控制在可接受范围 |

#### AC2 两种面试模式切换

##### 场景A：正常面试模式

| 字段 | 内容 |
|------|------|
| **Given** | 求职者选择「正常模式」 |
| **When** | AI发起提问 |
| **Then** | AI语气温和，基于求职者简历循序渐进抛出常规面试问题 |

##### 场景B：压力面试模式

| 字段 | 内容 |
|------|------|
| **Given** | 求职者选择「压力面试模式」 |
| **When** | 用户完成单次回答 |
| **Then** | AI语气严肃，针对回答内容持续追问、提出质疑、设置答题时限，还原高压面试场景 |

#### AC3 面试复盘报告生成

| 字段 | 内容 |
|------|------|
| **Given** | 求职者完成整场模拟面试 |
| **When** | 面试结束页面加载完成 |
| **Then** | 系统自动生成完整复盘报告，包含以下内容：<br>1. 综合面试通过/不通过判定；<br>2. 每道题目得分、回答要点完整评分；<br>3. 语音流畅度、表达逻辑分析；<br>4. 针对回答薄弱题目提供标准黄金回答建议 |
