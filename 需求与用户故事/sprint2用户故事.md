## 1 用户故事1：岗位的智能发布与跨平台查看

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-1 |
| 功能模块 | 岗位管理与岗位浏览 |
| 涉及角色 | 系统管理员、求职者 |

### 标准用户故事句式

1. **作为**系统管理员，**我希望**系统可根据输入关键词联网搜索、自动填充岗位完整信息，**以便**高效完成岗位录入与发布。
2. **作为**求职者，**我希望**可检索、筛选、查看全部开放岗位，**以便**快速找到匹配的工作机会。

### 用户价值

1. 降低HR/管理员手动录入岗位信息的时间成本，借助AI自动补齐标准化岗位内容；
2. 为求职者提供完整、实时、可筛选的职位库，消除岗位信息获取壁垒。

### 验收标准（AC）

#### AC1 管理员AI一键生成岗位能力

| 字段 | 内容 |
|------|------|
| **Given** | 管理员后台岗位新增页面，输入关键词「前端开发工程师 + 腾讯」 |
| **When** | 点击【AI一键生成】按钮 |
| **Then** | 系统自动联网检索，自动填充**岗位职责、任职要求、薪资范围**全部表单字段；填充后支持管理员对所有字段进行新增、查询、修改、删除操作 |

#### AC2 求职者岗位检索筛选能力

| 字段 | 内容 |
|------|------|
| **Given** | 求职者前端岗位列表页面，系统存在多条已发布开放岗位 |
| **When** | 求职者输入关键词，或选择薪资、工作地点筛选项 |
| **Then** | 页面实时展示符合条件的岗位列表，支持点击进入岗位详情页查看完整岗位信息 |

## 2 用户故事2：基于AI简历分析的精准职位推荐

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-2 |
| 功能模块 | AI智能岗位匹配推荐 |
| 涉及角色 | 求职者 |

### 标准用户故事句式

**作为**求职者，**我希望**系统自动解析我的简历，与全量岗位做多维度匹配，按综合匹配度排序展示推荐岗位，并展示AI生成的推荐理由，**以便**快速筛选高适配职位，节省海量浏览时间。

### 用户价值

消除求职者信息差，无需手动逐条对比岗位，系统自动完成简历-岗位匹配，快速定位高匹配工作，提升求职效率。

### 验收标准（AC）

#### AC1 简历-岗位匹配度计算

| 字段 | 内容 |
|------|------|
| **Given** | 求职者已上传并启用一份有效简历，系统存在岗位数据库 |
| **When** | 进入个人推荐页面 |
| **Then** | 系统读取简历信息，与全部岗位进行多维度打分，生成岗位匹配度数值 |

#### AC2 多维度复合排序

| 字段 | 内容 |
|------|------|
| **Given** | 系统已计算所有岗位匹配分数 |
| **When** | 求职者切换排序条件 |
| **Then** | 推荐列表支持按「综合匹配度、薪资、距离」三种维度复合排序展示 |

#### AC3 AI推荐理由展示

| 字段 | 内容 |
|------|------|
| **Given** | 推荐列表加载完成 |
| **When** | 求职者浏览岗位卡片 |
| **Then** | 每张岗位卡片固定展示AI生成的文字化推荐理由，示例：<br>1. 你的React商业项目经验与该岗位高度契合 95%<br>2. 该岗位急需懂跨平台开发的工程师，符合你的技术栈 |

## 3 用户故事3：多模式AI语音模拟面试与复盘

### 基础信息

| 项目 | 内容 |
|------|------|
| 需求编号 | P1-3 |
| 功能模块 | AI语音模拟面试 |
| 涉及角色 | 缺乏实战面试经验的求职者 |

### 标准用户故事句式

**作为**缺乏实战面试经验的求职者，**我希望**与AI进行实时语音对话面试，可切换正常/压力两种面试模式；面试结束后自动生成完整面试复盘报告与优化建议，**以便**线下真实面试前完成演练，提升面试能力、缓解面试紧张。

### 用户价值

低成本、无压力完成面试实战训练，提前熟悉面试提问逻辑，修正表达短板，同时掌握标准答题思路，应对真实面试。

### 验收标准（AC）

#### AC1 实时语音交互能力

| 字段 | 内容 |
|------|------|
| **Given** | 求职者进入模拟面试页面 |
| **When** | 点击【开始面试】 |
| **Then** | 1. AI通过语音播报面试问题；<br>2. 支持用户直接语音回答；<br>3. 内置语音转文字、文字转语音能力，交互延迟控制在可接受范围 |

#### AC2 两种面试模式切换

##### 场景A：正常面试模式

| 字段 | 内容 |
|------|------|
| **Given** | 求职者选择「正常模式」 |
| **When** | AI发起提问 |
| **Then** | AI语气温和，基于求职者简历循序渐进抛出常规面试问题 |

##### 场景B：压力面试模式

| 字段 | 内容 |
|------|------|
| **Given** | 求职者选择「压力面试模式」 |
| **When** | 用户完成单次回答 |
| **Then** | AI语气严肃，针对回答内容持续追问、提出质疑、设置答题时限，还原高压面试场景 |

#### AC3 面试复盘报告生成

| 字段 | 内容 |
|------|------|
| **Given** | 求职者完成整场模拟面试 |
| **When** | 面试结束页面加载完成 |
| **Then** | 系统自动生成完整复盘报告，包含以下内容：<br>1. 综合面试通过/不通过判定；<br>2. 每道题目得分、回答要点完整评分；<br>3. 语音流畅度、表达逻辑分析；<br>4. 针对回答薄弱题目提供标准黄金回答建议 |
