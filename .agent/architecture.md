# AI 智能简历与求职助手 - 系统架构文档

## 1. 项目概述
本项目职通车是一款AI智能简历与求职助手，是一款面向求职者的Web应用。核心能力包含简历智能优化、岗位匹配推荐、模拟 HR 面试、PDF 简历导出四大模块，通过大语言模型与匹配算法提升求职效率与简历质量。

项目采用前后端分离架构，基于 Vue3 + SpringBoot3 技术栈构建，支持容器化部署。

## 2. 技术栈选型

### 2.1 整体技术基底
- 前端核心：Vue3 
- 后端核心：SpringBoot 3.x
- 数据库：MySQL+Redis（可选）+MongoDB（可选）

### 2.2 前端技术栈
| 技术 | 用途 |
|------|------|
| Vue 3 | 前端核心框架，统一使用 Composition API |
| Vite | 构建工具，提供快速开发与打包能力 |
| Pinia | 全局状态管理，替代 Vuex |
| Element Plus | UI 组件库，统一交互风格 |

### 2.3 后端技术栈
| 技术 | 用途 |
|------|------|
| SpringBoot 3.x | 后端应用框架 |
| MyBatis-Plus | ORM 持久层框架，简化数据库操作 |
| Spring Security | 认证与权限控制框架 |
| Knife4j / Swagger | 接口文档自动生成 |

### 2.4 AI 能力支撑
- 大模型 API：阿里云API，负责简历文本优化、模拟面试对话生成
- 开发辅助：Claude Code 辅助代码生成与重构
- 核心算法：简历多维度评分权重计算、岗位文本相似度匹配、模拟面试对话状态机

### 2.5 部署与运维
- Docker：应用容器化打包
- Nginx：前端静态资源代理 + 后端接口反向代理

## 3. 整体架构设计
项目采用经典三层前后端分离架构，自上而下分为：
1. **表现层**：前端 Web 页面，负责用户交互与数据展示
2. **服务层**：后端业务服务，处理核心逻辑与 AI 能力对接
3. **数据层**：数据库，存储用户、简历、岗位等业务数据

同时数据层独立出AI能力适配层，统一封装第三方大模型调用，实现模型可插拔切换。

## 4. 核心模块设计

### 4.1 前端模块划分
- **用户中心模块**：邮箱注册登录、验证码验证、个人基本信息管理、Token自动刷新
- **简历管理模块**：简历信息录入、分段编辑、实时预览、版本保存、历史记录查看
- **简历导入导出模块**：支持Word/PDF/JPG格式导入（OCR识别）、Word/PDF格式导出
- **AI优化模块**：一键润色、措辞优化、改进建议生成、雷达图评分展示
- **智能填写助手模块**：实时对话生成简历内容、多轮迭代修改、采纳/复制功能、反馈机制
- **岗位管理模块**：岗位库浏览、搜索筛选、岗位详情查看、管理员CRUD操作
- **岗位匹配模块**：简历-岗位匹配度计算、多维度排序（匹配度/薪资/距离）、AI推荐理由生成
- **模拟面试模块**：语音对话交互、正常/压力两种模式、面试问题生成、回答反馈、面试复盘报告
- **模板广场模块**：智能推荐简历模板、一键套用自动填充、侧边预览/一键换肤、分类筛选
- **多语言翻译模块**：中英互译、专业术语保留、对照预览、二次编辑
- **系统公共模块**：全局布局、权限拦截、通用组件

### 4.2 后端模块划分
- **用户认证模块**：基于 Spring Security 实现账号注册登录、邮箱验证码、JWT 鉴权、Refresh Token 刷新机制
- **简历业务模块**：简历 CRUD、数据校验、版本管理、历史记录持久化
- **文件处理模块**：Word/PDF文本提取、JPG OCR识别、文件格式转换
- **AI适配模块**：统一封装大模型 API，管理 Prompt 模板，处理请求限流与结果解析
- **评分匹配模块**：实现简历多维度权重评分算法（教育背景、工作经历、项目经验、技能匹配、成果量化、排版规范）、岗位文本相似度计算与排序
- **模拟面试模块**：对话状态机管理、会话上下文维护、面试记录持久化、语音转文字/文字转语音能力集成
- **文件导出模块**：PDF/Word 模板渲染、文件生成与临时存储
- **模板管理模块**：模板CRUD、智能推荐算法、模板与用户信息匹配填充
- **翻译模块**：多语言翻译调用、专业术语库维护、翻译结果润色
- **岗位管理模块**：岗位CRUD、AI联网搜索自动填充岗位信息
- **通用基础模块**：统一返回封装、全局异常处理、接口文档、参数校验

### 4.3 核心算法与机制（AI 禁飞区 - 自研逻辑）
1. **简历多维度权重评分**：从教育背景、工作经历、项目经验、技能匹配、成果量化、排版规范6个维度设置权重，量化计算简历得分（0-100分）
2. **岗位相似度匹配排序**：基于文本特征与关键词匹配度，计算简历与岗位的契合度并排序输出，支持综合匹配度、薪资、距离多维度复合排序
3. **模拟面试对话状态机**：维护面试流程状态（开场-提问-追问-总结），控制多轮对话的上下文与节奏，支持正常/压力两种模式切换
4. **模板智能推荐算法**：根据用户工作年限、行业、目标岗位智能推荐适配简历模板

## 5. 核心业务流程
### 5.1 用户注册登录流程
用户输入邮箱密码 → 发送验证码 → 验证验证码 → 注册成功 → 登录生成JWT Token → Token过期自动刷新

### 5.2 简历导入流程
用户上传Word/PDF/JPG文件 → 后端解析文件（OCR识别图片）→ 提取文本内容 → 结构化简历数据 → 返回前端编辑

### 5.3 简历优化流程
用户填写/上传简历 → 后端组装优化 Prompt → 调用大模型 API → 解析优化结果 → 返回前端展示雷达图评分与改进报告

### 5.4 智能填写助手流程
用户输入口语化经历描述 → 后端生成优化 Prompt → 调用大模型生成专业简历语句 → 返回结果 → 用户多轮迭代修改 → 采纳/复制到简历

### 5.5 岗位管理流程（管理员）
管理员输入岗位关键词 → 调用AI联网搜索 → 自动填充岗位信息 → 管理员编辑确认 → 保存到岗位库

### 5.6 岗位匹配流程
用户进入推荐页面 → 提取简历核心特征 → 与全量岗位多维度匹配 → 计算匹配度得分 → 支持多维度排序（匹配度/薪资/距离）→ 生成AI推荐理由 → 返回排序结果

### 5.7 模拟面试流程
用户选择面试模式（正常/压力）→ 初始化对话状态机 → 大模型生成首道面试题 → 语音播报问题 → 用户语音/文字作答 → 模型追问/点评 → 循环直至面试结束 → 生成面试复盘报告

### 5.8 模板广场流程
用户进入模板广场 → 系统根据用户信息智能推荐模板 → 用户选择模板 → 自动填充个人信息 → 实时预览效果 → 确认使用

### 5.9 多语言翻译流程
用户选择翻译方向（中译英/英译中）→ 后端调用翻译API → 专业术语处理 → 润色优化 → 对照预览展示 → 支持二次编辑

## 6. 数据架构
### 核心数据表
- 用户表：存储账号、密码、基础信息（姓名、手机号、出生日期、学历、工作年限、城市）
- 简历主表：简历基础信息、关联用户、评分结果、版本号
- 简历明细表：分段存储教育经历、工作经历、项目经验、技能等
- 岗位信息表：岗位库数据、岗位描述、任职要求、薪资范围、工作地点
- 面试会话表：面试记录、对话历史、状态快照、面试模式、复盘报告
- 模板信息表：模板分类、模板内容、适用场景
- 翻译术语表：专业术语中英文对照、领域分类
- 系统配置表：AI 模型配置、评分权重参数、模板配置

## 7. 部署架构
采用 Docker 容器化部署方案：
1. 前端项目打包为静态资源，构建 Nginx 镜像提供 Web 服务
2. 后端 SpringBoot 项目构建为 Jar 包镜像，独立容器运行
3. 数据库可采用容器部署或独立云数据库
4. 外层 Nginx 统一入口，负责静态资源分发与后端接口反向代理
