## 2. 质量门禁怎么过

### 2.1 测试覆盖 ≥60% + 3 边界

当前缺口大：后端大约只有

- `TemplateServiceTest`
- `ResumeExportServiceTest`
- `ResumeSummaryStoreTest`
- `TemplateExportIntegrationTest`（易 skip）

**今日最低补齐建议：**

1. `pom.xml` 加 JaCoCo，CI/本地报告 HTML  
2. 边界三例（可写入 §3）：  
   - 工作年限 `"3-5年"` 推荐年份解析  
   - 多条 SUMMARY 时取最新而非最长  
   - 超长正文 PDF 多页（已有测可保留）  
3. 再补：空 templatePath、过期 export 下载、岗位 fork 自己岗位

### 2.2 代码走查

每人打开别人 MR 或文件，留下：

- 审查人 / 被审人 / 日期  
- 文件路径  
- ≥1 条实质意见（安全/边界/可维护性）  
- 是否已修改  

### 2.3 AI 反思日志模板（每功能点一段）

```
功能点：________
问了 AI 什么：
AI 给了什么（可贴摘要）：
我们改了什么（为什么不直接用）：
残留风险：
```

建议覆盖：模板导出、SUMMARY 落盘、岗位 Fork、匹配打分、前端岗位社区。

### 2.4 性能证据

- 浏览器：打开首页 → Network 清空 → 刷新 → 截「DOMContentLoaded / Load」  
- API：登录后打 `GET /api/v1/templates`、`GET /api/v1/jobs`（或你们的列表接口）用 Network Timing 或 `curl -w "%{time_total}"`  
- 阈值仍 &gt;500ms：写明原因（冷启动、AI 调用除外；**统计非 AI 同步读接口**）
