# Sprint 3 开发计划

## 一、迭代目标

完成 **AI语音模拟面试模块**、**联网搜索JD与岗位推荐完善模块**、**简历模板完善模块** 三大功能的开发，实现完整对话面试（支持语音/文字输入，输出附带语音的文字）、面试复盘报告与知识图谱、联网链接可访问性校验、简历模板问题修复。依赖 Sprint 1 和 Sprint 2 已完成的所有模块。

## 二、团队分工

| 成员       | 职责范围                        | 负责模块                           |
| -------- | --------------------------- | ------------------------------ |
| **yang** | AI语音模拟面试前端开发                | 语音模拟面试前端                       |
| **wang** | 面试复盘报告与知识图谱后端、联网搜索完善        | 复盘报告与知识图谱后端、联网搜索JD与岗位推荐完善      |

| **tian** | 语音接口调通、简历模板修复、AI语音模拟面试提示词设计 | 语音识别/合成接口、简历模板完善、AI语音模拟面试提示词设计 |

## 三、模块任务清单

> 注：模块间依赖关系——tian的语音接口和提示词设计需先完成，he的面试后端依赖tian的语音接口和提示词；wang的复盘报告依赖he的面试数据产出和tian的提示词；yang的前端依赖所有后端API定义。简历模板完善模块与其他模块互不依赖，可独立开发。

### 1. 成员 he - AI语音模拟面试后端（除语音接口外）

#### 1.1 AI语音模拟面试模块

> 技术方案：必须设计对话状态机，具体状态设计方案需在开发前评审确定。

- 设计对话状态机
- 设计面试记录表结构
- 设计面试对话记录表结构
- 实现面试开始接口（根据目标岗位生成面试问题，启动对话状态机）
- 实现问题生成接口（调用大模型根据岗位JD和简历生成面试问题）
- 实现回答处理接口（接收用户回答，调用大模型进行评估，生成下一个问题或结束面试）
- 实现面试结束接口（触发状态机终止，生成面试总结数据供复盘使用）
- 实现面试历史记录查询接口
- 实现WebSocket连接管理（面试实时对话消息推送）
- 实现WebSocket消息协议（消息类型定义、序列化格式）
- 实现WebSocket断线重连与消息恢复机制

---

### 2. 成员 tian - 语音接口调通、简历模板修复、AI语音模拟面试提示词设计

#### 2.1 语音识别与语音合成接口调通

- 实现语音识别接口封装（接收音频文件，返回识别文本）
- 实现语音合成接口封装（接收文本，返回音频文件）
- 实现语音文件上传与临时存储方案
- 实现语音接口错误处理与重试机制

#### 2.2 AI语音模拟面试提示词设计

- 设计面试问题生成提示词（基于岗位JD和简历生成针对性面试问题）
- 设计面试回答评估提示词（评估用户回答质量，给出反馈）
- 设计面试总结生成提示词（生成面试综合评价和改进建议）

#### 2.3 简历模板完善模块

- 排查现有简历模板，列出无法正常使用的模板清单，并进行修复

### 3. 成员 wang - 面试复盘报告与知识图谱、联网搜索完善

#### 3.1 面试复盘报告与知识图谱后端

- 实现复盘报告生成接口（基于面试对话记录，调用大模型生成综合评价）
- 实现知识图谱数据生成接口（分析简历能力与岗位要求差距，生成结构化数据）
- 实现复盘报告查询接口
- 实现知识图谱数据查询接口（支持节点关系展示）

#### 3.2 联网搜索JD与岗位推荐完善模块

- 实现AI返回链接可访问性校验接口（检查链接是否能正常访问）

## 四、验收标准

### AI语音模拟面试

| 编号    | 验收条件                              |
| ----- | --------------------------------- |
| AC1.1 | 用户选择简历和目标岗位后，点击"开始面试"，系统生成第一个面试问题 |
| AC1.2 | 用户可选择文字输入或语音输入方式回答问题              |
| AC1.3 | 用户使用语音输入时，系统能正确识别语音内容并转为文字        |
| AC1.4 | AI回答以文字形式展示，并支持点击播放语音             |
| AC1.5 | 面试过程中展示当前状态、问题序号和进度条              |
| AC1.6 | 面试结束后，系统生成复盘报告，包含综合评价、优缺点、改进建议    |
| AC1.7 | 知识图谱可视化展示现有能力与目标岗位要求之间的差距         |
| AC1.8 | 用户可在面试历史记录页面查看过往面试记录和复盘报告         |
