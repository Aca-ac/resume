# Sprint 2 开发计划

## 一、迭代目标

完成 **简历模板与模板化导出模块**、**个人目标岗位管理模块**、**简历-岗位匹配推荐模块** 三大功能的开发，实现简历模板选择与自动填充导出、用户目标岗位的 AI 联网搜索补全、以及简历与目标岗位的多维度匹配排序。依赖 Sprint 1 已完成的用户认证、简历导入与分段管理、AI 适配模块。

## 四、数据结构设计

### 核心数据表
- **模板信息表（resume_templates）**：id、name、category、preview_url、template_path、applicable_scene、created_at、updated_at
- **目标岗位表（target_jobs）**：id、user_id、job_title、company、jd_content、requirements、salary_range、location、source（MANUAL/AI_SEARCH）、created_at、updated_at
- **匹配记录表（match_records）**：id、user_id、resume_id、job_id、match_score、dimension_scores（JSON：技能/经验/学历/整体契合度）、reason（AI 推荐理由）、created_at

### 与 Sprint 1 表的关系
- `target_jobs.user_id` 关联 `users.id`，每个用户维护自己的目标岗位列表
- `match_records.resume_id` 关联 `resumes.id`，`match_records.job_id` 关联 `target_jobs.id`
- 匹配算法读取 `resumes` + `resume_details` 作为简历侧特征，读取 `target_jobs` 作为岗位侧特征

### 技术方案待定项
| 模块 | 待定项 | 候选方案 |
|------|--------|----------|
| 模板导出 | 模板渲染引擎 | poi-tl（Word）/ Freemarker / Thymeleaf |
| 模板导出 | PDF 转换方案 | LibreOffice 命令行 / Aspose / Apache POI + iText |
| 岗位匹配 | 匹配算法 | 关键词匹配 / TF-IDF 向量相似度 / 大模型嵌入向量召回 |
| AI 联网搜索 | 搜索能力来源 | 阿里云大模型联网搜索插件 / 第三方搜索 API |
