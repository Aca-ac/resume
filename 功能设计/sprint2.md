# Sprint 2 开发计划

## 一、迭代目标

完成 **简历模板与模板化导出模块**、**个人目标岗位管理模块**、**简历-岗位匹配推荐模块** 三大功能的开发，实现简历模板选择与自动填充导出、用户目标岗位的 AI 联网搜索补全与社区化管理、基于简历的岗位推荐（直接联网获取与平台内数据获取分开处理）。依赖 Sprint 1 已完成的用户认证、简历导入与分段管理、AI 适配模块。

> 注：岗位管理模块、岗位匹配模块与简历模版模块互不依赖。简历模版模块只对简历样式、排版进行优化，不改变内容；岗位匹配模块只需要读取简历内容即可进行匹配。

> 注：平台内数据获取可获取所有用户创建的岗位，包括用户自己保存的目标岗位，无需单独的"基于用户已保存的目标岗位进行匹配"功能。

## 三、模块任务清单

### 1. 成员 wang - 岗位相关后端开发

#### 1.1 个人目标岗位管理模块（对应架构文档 4.1.6、4.2.10）


- 实现目标岗位 CRUD 接口（用户手动添加、编辑、删除自己的目标岗位）
- 实现 AI 联网搜索接口（根据岗位名称和已有JD调用大模型联网搜索，自动修正+补全岗位JD）
- 实现岗位社区功能接口（查看所有用户发布的岗位、fork他人岗位创建自己的版本、支持根据岗位名称或岗位id查询岗位）
- 实现岗位评论功能接口（用户可在岗位信息下查看所有评论、发表文字评论）


#### 1.2 简历-岗位匹配推荐模块（对应架构文档 4.1.7、4.2.5）

> 技术方案待定：匹配算法选型（关键词匹配 / TF-IDF 向量相似度 / 大模型嵌入向量召回）需在开发前评审确定。

**直接联网获取**：
- AI直接联网搜索获取岗位信息
- 返回岗位信息、匹配度评分、判断理由、来源（联网搜索到的网页链接，供用户交叉验证）
- 没有合适匹配结果直接返回空列表

**平台内数据获取**：
- 使用语义向量余弦值计算筛选出平台内匹配度最高的2个岗位（平台内数据包含所有用户创建的岗位，包括用户自己保存的目标岗位）
- 让AI给出岗位信息、匹配度评分、判断理由、来源（说明是平台内数据并附上岗位id）
- 匹配度低于30分的岗位直接从列表中删掉

**结果整合**：
- 整合直接联网获取与平台内数据获取的结果
- 如果两边都没有匹配结果，调用AI给出改进建议，如实告诉用户简历存在严重问题


#### 1.3 基础设施补充（对应架构文档 4.2.3、4.2.11）

- 扩展 AI 适配模块，支持联网搜索能力（大模型联网搜索调用与结果解析）
- 扩展 Prompt 模板管理（岗位 JD 补全、匹配理由生成的 Prompt 模板，严格输出格式）
- 补充匹配算法相关的可配置参数管理
- 实现岗位信息交叉验证机制（给出来源供用户交叉验证）

## 四、验收标准

### 简历模板与模板化导出
| 编号 | 验收条件 |
|------|----------|
| AC1.1 | 用户进入模板广场，可按分类筛选模板，查看模板缩略图预览 |
| AC1.2 | 系统根据用户工作年限、行业、目标岗位智能推荐适配模板，推荐模板有明显标记 |
| AC1.3 | 用户选择模板后，系统自动读取个人信息与简历分段内容填充至模板，支持侧边实时预览 |
| AC1.4 | 用户点击"导出"，可选择导出为 .docx 或 .pdf 格式，文件内容与当前简历一致 |
| AC1.5 | 导出文件排版整洁、无乱码，模板样式正确渲染，符合正式投递标准 |
| AC1.6 | 支持一键换肤（切换不同模板），切换后自动重新填充并预览 |
