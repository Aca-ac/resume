# 简历分析模块数据库设计

## 1. 概述

本模块数据库设计严格基于项目中已有的数据库迁移脚本 V6 和 V8，用于存储简历与职位描述（JD）的匹配记录及各维度评分数据。

## 2. 表结构设计

### 2.1 match_records 表（JD职位匹配记录）

#### 2.1.1 基础字段（V6版本）

| 字段名 | 数据类型 | 约束 | 默认值 | 注释 |
| :--- | :--- | :--- | :--- | :--- |
| id | BIGINT UNSIGNED | NOT NULL, PRIMARY KEY, AUTO_INCREMENT | - | 匹配记录ID |
| user_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 用户ID |
| resume_id | BIGINT UNSIGNED | NOT NULL, FOREIGN KEY | - | 简历ID |
| jd_text | MEDIUMTEXT | NOT NULL | - | 职位描述原文 |
| match_score | INT UNSIGNED | NOT NULL | 0 | 匹配分 0-100 |
| analysis | MEDIUMTEXT | NULL | - | 匹配分析说明 |
| created_at | DATETIME | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

#### 2.1.2 扩展字段（V8版本）

| 字段名 | 数据类型 | 约束 | 默认值 | 注释 |
| :--- | :--- | :--- | :--- | :--- |
| summary_score | INT UNSIGNED | NOT NULL | 0 | 个人总结评分 0-100 |
| education_score | INT UNSIGNED | NOT NULL | 0 | 教育背景评分 0-100 |
| experience_score | INT UNSIGNED | NOT NULL | 0 | 工作经历评分 0-100 |
| skill_score | INT UNSIGNED | NOT NULL | 0 | 专业技能评分 0-100 |
| project_score | INT UNSIGNED | NOT NULL | 0 | 项目经历评分 0-100 |

#### 2.1.3 索引设计

| 索引名称 | 类型 | 字段 | 说明 |
| :--- | :--- | :--- | :--- |
| PRIMARY | 主键索引 | id | 唯一标识匹配记录 |
| idx_user_id | 普通索引 | user_id | 加速按用户ID查询 |
| idx_resume_id | 普通索引 | resume_id | 加速按简历ID查询 |
| idx_created_at | 普通索引 | created_at | 加速按创建时间排序查询 |

#### 2.1.4 外键约束

| 约束名称 | 外键字段 | 关联表 | 关联字段 | 删除策略 |
| :--- | :--- | :--- | :--- | :--- |
| fk_match_user | user_id | users | id | CASCADE |
| fk_match_resume | resume_id | resumes | id | CASCADE |

#### 2.1.5 表属性

- **存储引擎**: InnoDB
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_unicode_ci
