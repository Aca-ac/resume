**四、 遇到的问题与困难**

*   **技术问题：**
    *   PDF 导出中文乱码/缺字、个别生僻偏旁字形导致 PDFBox 失败；前端误请求 `/api/...`（缺 `v1`）被当成静态资源返回 500。
    *   **已尝试的解决方案：** 优先加载本机 CJK 字体（如 SimHei）、NFKC 规范化与缺字替换；统一前端 API 为 `/api/v1/...` 并 unwrap `Result`；本地用真实中文简历与接口冒烟验证。
    *   **需要帮助或待解决：** 分析模块 Key 配置统一需尽快改；Security 收紧需组内确认公开白名单（登录/注册/验证码等）。
*   **非技术问题：**
    *   多人并行改 `main`（UI、OCR 回滚、Flyway 等），分支易落后，合并冲突与重复 MR 较多。
    *   **已采取的措施：** 提 MR 前先 `fetch` + 同步 `main`；先走 GitHub CI 再开 GitLab MR；接口文档与代码变更分开提交，便于评审。
