# Sprint 1 开发计划

## 一、迭代目标

完成 **用户认证模块**、**简历导入导出模块**、**AI简历智能分析模块** 三大核心功能的开发，实现用户邮箱注册登录、简历多格式导入导出、AI多维度评分与优化建议功能。

## 三、验收标准

### 用户注册与登录
| 编号 | 验收条件 |
|------|----------|
| AC1.1 | 用户输入有效邮箱和密码后，系统发送6位数字验证码至该邮箱，输入正确验证码后完成注册 |
| AC1.2 | 注册成功后，用户可使用邮箱+密码登录，登录后生成 JWT Token 用于后续请求鉴权 |
| AC1.3 | Token 过期后，系统自动使用 Refresh Token 刷新，用户无感知（无需重新登录） |
| AC1.4 | 登录成功后进入个人中心，用户可填写/修改：姓名、手机号、出生日期、最高学历、工作年限、所在城市 |
| AC1.5 | 个人中心信息保存后，在简历模板中可自动读取并填充（如姓名、电话等字段） |

### 简历导入与导出
| 编号 | 验收条件 |
|------|----------|
| AC2.1 | 用户点击"导入简历"，支持选择 .doc / .docx / .pdf / .jpg 格式文件上传 |
| AC2.2 | Word 文件导入后，系统能提取正文文本，保留段落结构，准确率≥90% |
| AC2.3 | PDF 文件导入后，系统能提取正文文本，准确率≥90% |
| AC2.4 | JPG 文件导入后，系统调用 OCR 识别文字，准确率≥70%（展示识别结果供用户手动修正） |
| AC2.5 | 用户点击"导出"时，可选择导出为 .docx 或 .pdf 格式，文件内容与当前简历一致 |
| AC2.6 | 导出文件排版整洁，无乱码，符合正式投递标准 |

### AI简历智能分析
| 编号 | 验收条件 |
|------|----------|
| AC3.1 | 用户点击"AI智能分析"后，系统在5-15秒内返回分析结果（含加载中状态提示） |
| AC3.2 | 雷达图展示至少6个维度的评分：教育背景、工作经历、项目经验、技能匹配、成果量化、排版规范，每个维度0-100分 |
| AC3.3 | 雷达图使用 ECharts 渲染，支持鼠标悬停查看具体分数 |
| AC3.4 | 分析结果下方列出修改建议列表，每条建议包含：原文定位（如"工作经历-第3行"）、问题描述、优化建议、修改示例 |
| AC3.5 | 修改建议至少包含5条，覆盖至少4个维度 |
| AC3.6 | 用户可点击"应用建议"一键将修改示例应用到简历中，或点击"忽略"跳过该条建议 |
| AC3.7 | 分析记录存入数据库，用户可在历史记录中查看过往分析报告 |

## 四、数据结构设计

### 核心数据表
- **用户表（user）**：id、email、password、name、phone、birthday、education、work_years、city、refresh_token、created_at、updated_at
- **简历主表（resume）**：id、user_id、title、version、created_at、updated_at
- **简历明细表（resume_detail）**：id、resume_id、section_type（教育经历/工作经历/项目经验/技能）、content、sort_order
- **分析记录表（analysis_record）**：id、user_id、resume_id、score_json（各维度评分）、suggestions（建议列表JSON）、created_at
