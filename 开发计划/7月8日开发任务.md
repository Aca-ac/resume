## 三、任务验收标准参考

### 用户认证模块
| 编号    | 验收条件                                            |
|-------|-------------------------------------------------|
| AC1.1 | 用户输入有效邮箱和密码后，系统发送6位数字验证码至该邮箱，输入正确验证码后完成注册       |
| AC1.2 | 注册成功后，用户可使用邮箱+密码登录，登录后生成 JWT Token 用于后续请求鉴权     |
| AC1.3 | Token 过期后，系统自动使用 Refresh Token 刷新，用户无感知（无需重新登录） |
| AC1.4 | 登录成功后进入个人中心，用户可填写/修改：姓名、手机号、出生日期、最高学历、工作年限、所在城市 |


### 简历导入导出模块
| 编号    | 验收条件                                              |
|-------|---------------------------------------------------|
| AC2.1 | 用户点击"导入简历"，支持选择 .doc / .docx / .pdf / .jpg 格式文件上传 |
| AC2.2 | Word 文件导入后，系统能提取正文文本，保留段落结构，准确率≥90%               |
| AC2.3 | PDF 文件导入后，系统能提取正文文本，准确率≥90%                       |
| AC2.4 | JPG 文件导入后，系统调用 OCR 识别文字，准确率≥70%（展示识别结果供用户手动修正）    |
| AC2.5 | 用户点击"导出"时，可选择导出为 .docx 或 .pdf 格式，文件内容与当前简历一致      |
| AC2.6 | 导出文件排版整洁，无乱码，符合正式投递标准                             |
